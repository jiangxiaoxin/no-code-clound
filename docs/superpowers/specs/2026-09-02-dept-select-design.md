# 部门单选 / 部门多选设计

日期：2026-09-02  
状态：已按简道云对齐修订  
范围：`type: 'dept'`（部门单选）、`type: 'dept-multiple'`（部门多选）的字段属性、弹框选部门、默认值、填报入库、列表展示。可放进主表、标签页和子表单。人员「按部门字段」只认部门单选。

对照：组织部门来自管理后台同一套表，填报走 `GET /api/org/departments`。和登录人部门 `currentUserDept` 不是同一个控件：登录人部门只读、不入库；本控件入库部门 id，可用「当前用户所在部门」当默认值。

## 1. 需求核对

| 原描述 | 判定 | 本期怎么定 |
|---|---|---|
| 参照简道云 | 清楚 | 属性拆成**可选范围**和**取值来源**两套；多选树开复选框，勾父级级联勾下级 |
| 可选范围：哪些部门可作为备选项 | 清楚 | `全部` / `自定义`。自定义勾选的部门及其下级是候选人。不做「按部门字段」（部门自己再引用另一个部门字段，简道云也没有） |
| 取值来源：字段默认选中的部门 | 清楚 | `自定义`=新建时不预填，手选；`当前用户所在部门`=空值时写入登录人第一个部门；`数据联动`=按条件从他表写入 |
| 多选弹框 el-tree 开复选框；选中父级则下级都被选中 | 清楚 | `show-checkbox`，`check-strictly` 关闭。提交存所有已勾节点 id（父级+下级） |
| 单选怎么选 | 补齐 | 单选树不出现复选框，点节点选一个，后点覆盖 |
| 库里存什么 | 沿用 | 单选正整数 id；多选去重保序的 id 数组。不存部门名 |
| 停用 / 删除 | 沿用 | 树里不出现停用部门。已选 id 部门还在就显示现名，不在了显示「已删除」 |
| 列表 / 导入 | 沿用 | 列表显示名称，不可内联编辑；导入跳过这两列 |

本期不做：设计器预置固定默认部门（除「当前用户所在部门」）、按部门列复杂筛选、导入部门列、跨应用。

## 2. 和现有能力怎么区分

| 能力 | 干什么 | 库里存什么 |
|---|---|---|
| 登录人部门 `currentUserDept` | 只读展示当前登录人部门名 | 不入库 |
| 部门单选 / 多选 | 从表单里选部门 | 部门 id / id 数组 |
| 人员「按部门字段」 | 用本表某个部门单选的值过滤候选人 | 读部门单选的 id |
| 数据联动 | 条件变化后自动写入 | 当前字段自己的值（部门 id） |

## 3. 字段配置

公共项：标题、占位、必填、宽度、tips、禁用、可修改。

拖入默认：

```json
{
  "type": "dept",
  "deptScope": "all",
  "optionSource": "custom"
}
```

多选只把 `type` 换成 `dept-multiple`。

`deptScope` 只允许 `all`、`custom`；缺省或非法按 `all`。

选 `custom` 后：

```json
"deptScopeConfig": {
  "departmentIds": [1, 2]
}
```

数组缺省当 `[]`。都空则运行时没有候选人（弹框「没有可选择的部门」）。勾选的每个 id 在运行时还包含其**下级**启用部门。

`optionSource`：

| 值 | 含义 |
|---|---|
| `custom` | 不预填。填报手选 |
| `current_user_dept` | 当前值为空时，写入登录人 `departmentIds[0]`（没有部门则仍空）。该 id 不在可选范围内则不写 |
| `linkage` | 按数据联动写入。单选按记录条数，多条清空并提示；多选收集 id |

属性面板（紧挨必填，不要用 `el-space`）：

1. **可选范围**：全部 / 自定义  
2. 自定义时：按钮「设置可选范围」；配完变为「已设置可选范围」，右侧清除二次确认。弹框可拖拽，里面是部门树（复选框，勾父级带下级）  
3. **取值来源**：自定义 / 当前用户所在部门 / 数据联动  
4. 数据联动时出现「设置数据联动」，与人员相同

画布：禁用预览，不打开弹框。已配联动时标题旁仍显示联动图标。

## 4. 值形状

部门单选：

```json
8
```

部门多选：

```json
[8, 9, 12]
```

- id 必须是正整数。  
- 多选去重、保序。勾父级时父级和下级都写入。  
- 空：单选不写该 key；多选按现有 `serializeValue` 空值规则。  
- 后端 `coerce`：`dept` 正整数；`dept-multiple` 正整数数组。  
- 不把部门名写入 Mongo。展示按 id 换当前名称。

## 5. 可选范围（候选人）

只统计 **启用中** 的部门。

| `deptScope` | 候选人 |
|---|---|
| `all` | 组织接口返回的整棵启用部门树 |
| `custom` | 所选部门 id 及其下级。名单空则没有候选人 |

自定义范围树里勾了父级，只存勾上的那些 id；运行时再展开下级。之后组织里新增的子部门也会进范围。

弹框只展示候选人。父级不在范围内、子级在范围内时，子级提到树根，不把不可选的祖先当成可选项。

已选但不在范围内的部门：控件上仍显示（能换名或「已删除」）；打开弹框时草稿只保留仍在范围内的 id。确定后按草稿写入。

联动写入**可以**带出当时不在可选范围里的部门（与人员一致）。手选仍受范围限制。

## 6. 运行时选部门弹框

点控件（清除 icon 除外）打开 `el-dialog`，`draggable`。标题「选择部门」。宽度约 520px。

结构：顶部已选区（标签 + 删除；无人时「未选择部门」）+ 部门树。

- **单选**：树无复选框。点节点高亮并作为草稿；点确定才写入。  
- **多选**：`el-tree` 开 `show-checkbox`，不要 `check-strictly`。勾父级则下级全勾；取消父级则下级全取消。部分子级勾选时父级半选。点确定写入所有已勾 id。  
- 自定义范围为空：不出现树，正文「没有可选择的部门」。  
- 底部取消 / 确定。取消不改控件上的值。

控件上每个已选部门一个标签，点关闭只去掉该项（多选去掉该 id；若去掉的是父级，已单独勾上的下级仍保留，直到用户在树里改）。

## 7. 取值来源（默认值）

在添加数据或详情编辑打开时，若当前值为空，按 `optionSource` 处理：

| `optionSource` | 空值时 |
|---|---|
| `custom` | 保持空 |
| `current_user_dept` | 写入登录人第一个部门 id（`departmentIds[0]`）。没有、或该 id 不在可选范围内：保持空。单选写整数，多选写单元素数组 |
| `linkage` | 走现有联动，不在这里预填登录人部门 |

用户已经选过或库里已有值时，不要用登录人部门覆盖。用户清空后，同一轮打开的表单不再自动填回（只在控件初次挂载且值为空时写一次）。

「当前用户所在部门」和登录人部门控件的区别：前者写入可改的部门字段；后者永远只读展示。

## 8. 子表

可以拖进子表单。行内单元格复用同一套弹框和范围。人员「按部门字段」仍只认 `type === 'dept'`。

## 9. 联动 / 其他表数据

`hasLinkageSource` 含 `dept`、`dept-multiple`。`sourceTypesFor`：单选对单选，多选对多选。「其他表数据」树不列出部门字段。
