# 部门单选 / 部门多选设计

日期：2026-09-02  
范围：`type: 'dept'`（部门单选）、`type: 'dept-multiple'`（部门多选）的设计、弹框选部门、填报入库、列表展示、数据联动。可放进主表、标签页和子表单。人员「按部门字段」只读部门单选。

对照：组织部门来自管理后台同一套表，填报走 `/api/org/departments`。和登录人部门 `currentUserDept` 不是同一个控件。

## 存什么

- 部门单选：一个正整数部门 id
- 部门多选：去重保序的正整数 id 数组
- 展示按 id 查当前部门名；部门已从组织消失显示「已删除」
- 导入跳过这两列；列表不能单元格内联编辑

## 填报

点控件打开「选择部门」弹框（可拖拽）。顶部是已选区，下面是启用部门树。点节点改草稿，点确定才写入。单选后点覆盖；多选再点一次取消。停用部门不出现在树里。

## 联动

取值来源与人员相同：自定义手选，或数据联动写入部门 id。部门单选匹配多条记录时清空并提示；部门多选收集 id。

## 子表

可以拖进子表单。人员在子表里把「按部门字段」配到同一行的部门单选时，按该行部门值过滤候选人。
