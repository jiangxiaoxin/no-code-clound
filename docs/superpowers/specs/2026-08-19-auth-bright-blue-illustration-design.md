# 登录注册页：明亮蓝插图分栏

日期：2026-08-19  
范围：只改登录页、注册页的视觉。鉴权逻辑、文案、校验规则不变。  
替代：`2026-08-18-auth-login-register-design.md` 中「登录页与注册页视觉」一节。该文档其余部分仍然有效。

## 目标

登录和注册改为左插图、右白底表单。整体明亮电光蓝，不再使用暗金毛玻璃和黄昏背景。

## 布局

桌面（`md` 及以上，Element Plus 断点 768px）：

- 整页 `el-row.auth-page`，两列无 gutter
- 左列 `el-col` 14/24（约 58%）：插图铺满高度，`background-size: cover`，`background-position: center`
- 右列 `el-col` 10/24（约 42%）：白底，表单垂直水平居中，内容最大宽度 420px
- 插图与表单并排，表单不叠在图上，不加暗色遮罩

窄屏（`< 768px`）：

- 两列都 `span=24`，插图在上、表单在下
- 插图区高度约 200px，人物允许裁切到上半身
- 表单区白底，全宽，内边距 32px 20px

登录 `/login` 与注册 `/register` 共用同一张插图和同一套右栏样式，只换标题和字段。

## 插图

一张扁平矢量图，保存为 `front/src/assets/auth-illustration.png`。

风格（对齐参考图，不照搬运动主题）：

- 纯色电光蓝底 `#1E50FF`，无渐变、无照片质感、无文字
- Corporate Memphis / 扁平矢量：小头、长颈、粗四肢、大躯干
- 粉彩非写实肤色：淡蓝、薄荷青、浅桃、浅薰衣草
- 五官、手指、鞋细节用细黑线；阴影极少
- 服装点缀：阳光黄 `#FFD84D`、薄荷绿 `#7EE8C5`、薰衣草 `#C4B5FD`、黑、白

人物（从左到右，无代码产品场景）：

1. 拖拽一块圆角黄色 UI 模块
2. 把彩色积木块叠成界面
3. 连接一朵带节点的白云
4. 指向一张悬浮的小仪表盘卡片

构图：四人横向排开，动态姿势，蓝底留出负空间。图中禁止任何字母、汉字、数字、水印。

## 右栏表单

去掉暗色半透明卡片、金描边、衬线标题、金色按钮。

| 元素 | 规格 |
|------|------|
| 右栏背景 | `#FFFFFF` |
| 主文字 | `#1A2332` |
| 次要文字 | `#6B7A90` |
| 品牌小字 | `No-Code Cloud`，`#1E50FF`，12px，字距加宽，uppercase |
| 标题 | 「登录」/「注册」，无衬线（沿用 IBM Plex Sans），约 36px，`#1A2332` |
| 输入框 | 浅底 `#F4F7FB`，描边 `#D7E0EE`，圆角 10px，高度 44px，字色 `#1A2332` |
| 聚焦 | 描边 `#1E50FF` |
| 主按钮 | 实心 `#1E50FF`，白字，全宽，高 46px，圆角 11px；hover `#1640D6` |
| 切换链接 | 正文 `#6B7A90`，链接 `#1E50FF` |

卡片本身不再做毛玻璃；右栏已是白底，`.auth-card` 只保留内边距。

文案、校验、接口行为保持现状（用户名/密码规则、注册成功跳登录、底部切换链接）。

## 实现边界

改动文件：

- 新增：`front/src/assets/auth-illustration.png`
- 修改：`front/src/styles/auth.less`
- 修改：`front/src/views/LoginView.vue`、`front/src/views/RegisterView.vue` 的模板结构（左视觉列 + 右表单列）

不改：后端、Pinia、路由守卫、首页（首页可继续暗色）。全局 `style.css` 的深色 `:root` 会把浅色字继承进表单，必须在 `.auth-page` 内覆盖为深字。

删除对 `auth-bg.jpg` 的引用和 `.auth-page::after` 噪点层。

## 成功标准

1. 桌面登录/注册：左侧亮蓝插图完整可见，右侧白底表单可读，无暗遮罩
2. 插图中无文字；四个人物是无代码场景，不是运动场景
3. 主按钮、品牌小字与插图底同为电光蓝
4. 窄屏插图在上、表单在下，表单仍可完整提交
5. 注册 → 登录 → 首页 → 退出 的原有流程不变
