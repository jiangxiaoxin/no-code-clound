# 部门负责人 需求设计

日期：2026-09-07  
状态：已定稿  
范围：管理后台给部门指定一位负责人；流程审批节点可以把「发起人所属部门的负责人」当作审批人来源。  
相关：

- 流程表单：`docs/superpowers/specs/2026-09-05-workflow-form-design.md`（当时写明组织里还没有负责人所以审批人不能选这一项，本设计把 §7.2 这项打开）

---

## 1. 一句话说清

一个人属于某个部门之后，可以标成**这个部门的负责人**。一个部门同一时间只能有一位。请假单这类流程可以把「发起人部门的负责人」配进审批节点，提交后待办派给这个人。

---

## 2. 怎么配负责人

入口仍是管理后台 **人员管理** 的新增 / 编辑人员，不在部门树上单独做「指定负责人」。

1. 先选部门。没选部门时，下面不出现负责人开关。
2. 选好部门后，部门这一项下面出现开关 **是否为部门领导**，默认关。
3. 打开表示这个人是**当前所选部门**的负责人。关掉、或把部门清空 / 换成别的部门，这个人不再是原部门的负责人。
4. 没有「分配部门」权限的人，部门和这个开关都不能改。

**新增人员**和**编辑人员**同一套规则。编辑时若这个人已经是当前部门的负责人，开关是开着的。

### 2.1 一个部门只能有一位，后来的顶替先前的

保存时如果这个部门已经有负责人，新打开开关的人直接成为负责人，原来的人变成普通成员，不用先去把原来的人关掉。

保存成功后：

- 发生了顶替：提示「已将某某部原负责人张三替换为李四」
- 没有原负责人：不提替换，和平时保存成功一样即可

### 2.2 列表上怎么看

- **人员管理**列表：部门那一列，若这个人是该部门负责人，部门名旁边标「负责人」。
- **部门管理**树：每个部门能看到当前负责人的姓名；没有则空着。

### 2.3 怎么存

负责人记在部门上，不记在人员表、也不另开一张表。

`department` 增加一列 `leaderUserId`（可空）：

- 有值：这个人是该部门负责人
- 空：该部门还没有负责人

一个人最多属于一个部门，所以一个人最多是一个部门的负责人。清掉或换走这个人的部门时，若 `leaderUserId` 正好是他，这一列一并清空。停用账号不自动摘掉负责人（部门树上仍能看到他，并标明已停用）；派待办时不派给停用账号，和现在其他审批人一样。

删部门仍按现有规则：有人挂在部门上就不能删。删掉之后负责人一起没了，不另做清理入口。

---

## 3. 流程里怎么用

审批节点属性里，在指定人员、指定角色、表单人员字段旁边加一个开关：**发起人所属部门的负责人**，默认关。

可以和现有三种来源一起勾，待办派给这些人的合集，同一人只一条。只勾这一个、不指定人员 / 角色 / 字段，也算配好了审批人，可以发布。

「限定与发起人同部门」仍然只作用于指定角色，不作用于这个开关。负责人本身就是发起人那个部门的人。

已经发布、正在审批的单据仍按提交时的图走。新勾了这个开关并发布后，只有之后新提交的单会按新规则派。

### 3.1 派待办时查谁

流转到该节点且开关开着时：

1. 查出请假人（发起人）所在部门
2. 看该部门的 `leaderUserId`
3. 这个人还在、账号启用，就加入待办名单

### 3.2 派不到人时

这一项派不到人的情况：发起人没挂部门、部门没有负责人、负责人已停用或账号已不存在。

- 同时还有指定人员或角色能派到人：单据照常走，只是名单里没有负责人。
- 所有来源加起来一个人都没有：单据进「异常」。若本来能派到人、只是负责人这一项落空，文案写「节点「部门审批」没有可用的发起人部门负责人」；其他来源也没有人时，仍用现在的「节点「xxx」没有可用的审批人」或「在发起人所在部门没有可用的审批人」。
- 点【重试】会重新查当前负责人。刚在人员管理里补上或重新启用，就能派出去。

发起人没部门时：**不要**再按「角色全公司派发」那条去给负责人找替补。负责人这一项就是空，角色若勾了「限定同部门」仍按现有规则退化成全公司并写进度说明。

---

## 4. 本期不做

- 一个部门多位负责人、正副职、代理人。
- 岗位、汇报关系、兼任、按上级逐级上报。
- 在部门编辑弹窗里指定负责人（只在人员表单上设）。
- 负责人自动跟随部门停用 / 人员停用而清空（停用后仍挂着，派单时跳过）。
- 把「部门负责人」做成和指定人员互斥的单独一类。

---

## 5. 手工怎么验收（摘要）

人员：选部门后才看到开关；默认关；打开保存后列表带「负责人」；同一部门再把另一个人打开开关，前一个人不再是负责人，并看到替换提示；清空部门后原部门没有负责人。

流程：请假单审批节点勾上「发起人所属部门的负责人」并发布；研发部员工提交，待办出现在该部负责人的【我的待办】；把负责人换成别人后再提一张，新单派给新人；发起人没有部门且节点只勾了负责人，单据进异常，文案带「没有可用的发起人部门负责人」。
