# 子表单设计

日期：2026-08-30  
状态：已实现  
参考：简道云 [子表单](https://hc.jiandaoyun.com/doc/9020)、[选择数据](https://hc.jiandaoyun.com/doc/9024)（第 3 节「子表单选择数据」）  
范围：主表字段 `type: 'subform'` 的设计配置、行内填报、入库校验、数据管理详情展示、子字段行内数据联动、子表整体数据联动、子字段下拉「其他表数据」的查询时机。不包含移动端、快速填报、子表字段权限配置、关联子表单、子表独立集合。

对照：调色板已有 `{ type: 'subform', label: '子表单', icon: Tickets }`。存储约定已把子表存成主表 `data` 里的数组，不建 `data.*` 索引。画布、填报目前是空占位。实现顺序由浅入深：先能设计/填/存，再选择数据，最后行内联动、整表联动。

## 1. 需求核对（简道云 → 本期）

| 简道云 9020 | 判定 | 本期怎么定 |
|---|---|---|
| 一对多明细，点「添加」增行 | 清楚 | 表格 + 添加 / 插入 / 复制 / 删除行 |
| 子字段从指定类型里选 | 清楚 | 只允许本项目已做成的填报类型；未做或没有的登记，不进子表 |
| 子字段属性与主表同类一致 | 清楚 | 选中子字段后复用现有属性面板；子表内再多一项「单条数据内不允许重复值」 |
| 必填：子表至少一行；子字段必填按行 | 清楚 | 见 §6 |
| 不允许重复值 / 单条数据内不允许重复值 | 清楚 | 子字段 `input`、`number`、`data`；提示文案不自定义 |
| 默认值：自定义多行或联动整表 | 清楚 | 默认空行数 + 整表联动（§7.5）。不做快速填报式预填 |
| 子字段数据联动 | 清楚 | 行内联动（§7.4），每行自己查、只写该行该列 |
| 子表整体数据联动 | 清楚 | 整表联动（§7.5），条件命中 1 条主表记录后覆盖整张子表 |
| 快速填报 / Excel 粘贴 | 明确不做 | 不做 |
| 字段权限：可新增 / 插入 / 编辑 / 删除 | 简化 | **不设开关**。填报时默认都能新增、插入、复制、编辑、删除行 |
| 电脑端表格、自动行高、固定前 N 列 | 部分要 | 只做电脑端表格；多行文本按内容撑高；可固定前 N 列 |
| 移动端纵向平铺 / 横向表格 | 明确不做 | 不做移动端样式 |
| 最多 200 行 | 清楚 | 超过不能再加，提示「子表单最多 200 行」 |
| 复制子表单带上全部子字段配置 | 清楚 | 与现有复制字段相同：子字段换新 `key` |
| 显隐规则、扫码加行、子表查询、公式汇总 | 项目没有或未做 | 登记，本期不做 |

本期不做：移动端、快速填报、子表权限组、嵌套子表、子表进 Excel 导入、数据管理单元格内联编辑子表、按子表字段筛选/排序、子表独立 Mongo 集合、关联子表单 `relate-subform`。

## 2. 和现有能力怎么区分

| 能力 | 干什么 | 库里存什么 |
|---|---|---|
| 子表单 `subform` | 一条主表记录带多行明细，行结构由表单设计定 | `data[子表key]` = 对象数组，每行只含子字段 key |
| 关联子表单 `relate-subform` | 多行来自另一张已有表 | 调色板已占位，不是本字段 |
| 选择数据 `data`（主表） | 人选他表一行，拷到当前主表若干字段 | 当前字段存源记录 id；被填充的主表字段存拷贝值 |
| 选择数据 `data`（子字段） | 人选他表一行或多行，生成本子表行，拷到**本行**其他列 | 该行存源记录 id；被填充的本行字段存拷贝值 |
| 行内联动 | 子表某一列配数据联动，每行自己查、只写这一行 | 写入该行该列自己的值 |
| 整表联动 | 整个子表配数据联动，条件成立后把他表某条记录的子表多行拷进来 | 覆盖 `data[子表key]` 整段数组 |

多个并列的子表单可以出现在同一张主表上。子表单里不能再放子表单。

## 3. 子字段范围

### 3.1 本期可拖进子表单

这些控件主表已经能填报、能入库，子表单元格复用同一套值形状和属性：

- 单行文本 `input`
- 多行文本 `textarea`
- 数字 `number`
- 日期 `date`、时间 `time`、日期时间 `datetime`
- 单选 `radio`、复选 `checkbox`
- 下拉单选 `select`、下拉多选 `select-multiple`
- 地址 `address`
- 图片 `image`
- 文件 `file`
- 选择数据 `data`
- 人员单选 `member`、人员多选 `member-multiple`
- 部门单选 `dept`、部门多选 `dept-multiple`

子字段的字典、其他表数据、取值/选项来源（含行内联动，见 §7.4）与主表同类相同。下拉的选项过滤里「当前表单字段」只列出**主表字段**。选择数据的过滤、行内联动的条件还可以引用**本子表其他列**。图片、文件属性与主表相同（张数/个数、大小、格式，图片另有压缩，文件另有是否可下载）；图片值仍是 URL 字符串数组，文件值仍是 `{ url, name }` 数组。选择数据属性与主表相同（数据源、显示字段、过滤、填充规则），填充目标只能是本子表其他列。这覆盖文件规格里「本期不拖进子表」的限制。

### 3.2 控件已有，子表内本期不做

主表已经做成，但单元格交互或查询比文本重，先不进子表。拖入时提示「该字段暂不支持添加到子表单」。

| 类型 | 原因 |
|---|---|
| 登录人姓名 `currentUser`、登录人部门 `currentUserDept` | 不是手填字段 |
| 分割线 `divider`、标签页 `tabs` | 布局，不是明细列 |

### 3.3 项目未完成或没有，只登记

简道云允许、本项目还不能当子字段的，登记如下。控件本身做完后，再单独立项「允许拖进子表」。

| 简道云名称 | 本项目 | 状态 |
|---|---|---|
| 成员字段 | `member` / `member-multiple` | 已允许进子表 |
| 部门字段 | `dept` / `dept-multiple` | 已允许进子表 |
| 定位 | — | 没有 |
| 查询 | — | 没有 |
| 手写签名 | — | 没有 |
| 流水号 | `serialNumber` | 调色板占位，控件未完成 |
| 关联数据 | `relate` | 控件未完成；简道云也不进子表 |
| 手机、OCR、按钮、计算、富文本 | — | 没有 |
| 子表单显隐规则 | — | 主表也还没有显隐规则 |
| 子表单扫码自动添加行 | — | 没有扫码 |
| 子表单查询 | — | 没有查询字段 |
| 子表单公式 / 行汇总 / 金额汇总 | — | 没有公式 |

不允许拖入：另一个 `subform`、`relate-subform`。

## 4. 字段配置

### 4.1 子表单本身

拖入画布时写入：

```json
{
  "type": "subform",
  "width": "1",
  "required": false,
  "disabled": false,
  "editable": true,
  "defaultRowCount": 0,
  "frozenCols": 0,
  "optionSource": "custom",
  "fields": []
}
```

公共项：标题、字段说明、必填、禁用、可修改。不设占位文字。宽度固定整行，属性里不出现宽度单选。

子表专有：

| 属性 | 含义 | 默认 |
|---|---|---|
| `fields` | 子字段数组，形状与主表字段相同（各有自己的 `key`） | `[]` |
| `defaultRowCount` | 新建填报时预留的空行数，整数 0–10。整表联动已配好时忽略（行来自联动） | `0` |
| `frozenCols` | 填报/详情时固定前 N 列，整数 0–5；列数不足则固定已有列 | `0` |
| `optionSource` | `custom` 自定义 / `linkage` 数据联动（整表，见 §7.5） | `custom` |

属性面板在校验设置下方增加：

1. 取值来源：自定义 / 数据联动。选数据联动后出现「设置数据联动」，弹框见 §7.5
2. 默认行数：数字输入，0–10；取值来源为数据联动且已配完时隐藏（行不靠默认空行）
3. 固定前 N 列：数字输入，0–5；文案「固定前 N 列」。画布不演示冻结，填报和详情生效
4. 子字段：列出已添加的子字段（标题 + 类型），可上移、下移、复制、删除；「添加子字段」打开允许类型列表（§3.1），点一项即追加

不出现：快速填报开关、可新增/插入/编辑/删除记录、移动端样式。

禁用：填报时整表只读，不能改单元格，也不能增删行。  
不可修改：新建可以填；打开已有记录编辑时整表锁住（含增删行），与主表图片/文件同一规则。

### 4.2 子字段

选中某一子字段后，右侧仍是现有字段属性（标题、占位、说明、校验、字典/来源等），按该类型显示。不出现宽度（子表是表格列，不走 12 栅格）。图片、文件列不出现占位文字，与主表一致。选择数据的「填充到」只列出**本子表**里可填报的其他列，不列出主表字段、其他子表、本列自己。

子字段 `input`、`number`、`data` 在「不允许重复值」下再增加一项：

- **单条数据内不允许重复值** `uniqueInRows`
- 只勾「单条数据内不允许重复值」可以
- 勾「不允许重复值」时自动勾上「单条数据内不允许重复值」，且不能单独关掉后者；关掉「不允许重复值」后，后者仍可单独留着

单条数据内不允许重复值：本次新增时，子表单里的数据之间，设定的字段不能重复值

不允许重复值：本次新增时，子表单设定的字段的值与数据库里不能出现重复值。

不允许重复值，自然也就不能允许单条数据内重复

不提供自定义重复提示。提示固定为 `[字段标题]不允许重复值`（跨记录）或 `[字段标题]同一子表内不允许重复值`（仅行内）。

复制子字段：新 `key`，配置深拷贝（含 `optionFilters`、`displayFieldKeys`、`fillMappings`；`fillMappings.targetKey` 若指向被复制列则改到新 `key`）。  
复制整个子表单：子表换新 `key`，每个子字段也换新 `key`，填充目标 key 和整表联动对照 `targetKey` 跟着换成新的子字段 key；`linkage` 深拷贝。

画布上复制按钮若仍隐藏，属性面板的复制仍然可用。

## 5. 设计器交互

主画布仍是 12 栅格。子表单格子占整行。

选中子表单：外框高亮，右侧编子表属性。  
选中子字段：点表格列头（或属性里的子字段行），右侧编该子字段；子表外框保持浅高亮。选中列时，列标题右侧出现删除图标；点过后二次确认，确认后删除该子字段（与属性面板删除相同）。

往子表里加列：

1. 从左侧调色板拖到子表区域（表头或表体）
2. 或属性里「添加子字段」

不允许的类型：不插入，`ElMessage.warning('该字段暂不支持添加到子表单')`。  
拖到子表外面的空白画布：仍是加主表字段（现有逻辑）。  
不能把已有主表字段拖进子表，也不能把子字段拖出变成主表字段。子字段只在本子表内排序。

画布预览：表头为子字段标题（必填列带头 `*`），表体一行禁用控件，不改 JSON、不查字典以外的运行时数据。已配字典的列可显示字典项预览，与主表画布一致。图片列用缩小的禁用上传占位，文件列用禁用的「上传文件」按钮，选择数据列用 `preview` 占位，都不请求接口。被填充的子列标题旁仍显示「受选择数据填充」图标；配了行内联动的列、配了整表联动的子表标题旁显示联动图标。底下有禁用的「添加」按钮占位。未加任何子字段时，表体提示「从左侧拖入字段到子表单」。

## 6. 值形状与校验

### 6.1 入库形状

```json
{
  "orderLines": [
    { "name": "A4纸", "qty": 2, "photos": ["/uploads/imgs/2026-08-30/a.jpg"] },
    { "name": "文件夹", "qty": 1, "product": "64b64c4c4c4c4c4c4c4c4c4c", "files": [{ "url": "/uploads/files/2026-08-30/x.pdf", "name": "说明.pdf" }] }
  ]
}
```

- 值是数组。不是数组则当成 `[]`。
- 每行只保留当前子字段 `key`，多出来的 key 丢掉。行内各字段按该类型现有 `coerceFieldValue` 转换；转失败整条记录 400「字段值类型不正确」。图片按主表规则存 URL 字符串数组，文件存 `{ url, name }` 数组，选择数据存源记录 id 字符串。
- 整行都空（各子字段按主表规则都算空）的行：若该行没有任何必填子字段，写入前丢掉；若有必填子字段，400 `[子表标题.子字段标题]不能为空`。图片无 URL、文件无项、选择数据无 id 都视为空。
- 丢掉空行后多于 200 行 → 400「子表单最多 200 行」。
- 子表没有子字段时，值只能是 `[]`。

不另存行 id。前端用下标或临时 id 做 Vue `key`，不入库。

空子表：`[]`。缺省 key 且未提交该字段时，与现在一样可以不写该 key；提交了则写 `[]`。

### 6.2 必填

1. **子表必填**：丢掉空行后至少 1 行，否则 400 `[子表标题]不能为空`。
2. **子字段必填**：表格里还在的每一行都要填。点「添加」出来的空行、默认行数铺出来的空行，只要该行有必填子字段，保存就拦 `[子表标题.子字段标题]不能为空`。某一行里只填了别的列、必填列仍空，同样拦截。没有必填子字段的空行仍会丢掉、不入库。
3. 想「子表至少有一行、且每列都有值」：每个子字段开必填，并给子表开必填。

前端提交前做同样判断，避免只靠接口。

### 6.3 重复值

只处理子字段 `type` 为 `input`、`number` 或 `data`，且对应开关打开。空值不参与。数字 `0` 要参与（与主表数字唯一一致）。选择数据按源记录 id 比。

| 开关 | 范围 |
|---|---|
| `uniqueInRows` | 当前这条主表记录的子表多行之间 |
| `unique` | 本表全部记录的该子表该列（任意一行） |

`unique` 为真时必须同时满足 `uniqueInRows`（保存字段 JSON 时写上）。

跨记录查询：`existsByDataValue(formId, 子表key.子字段key, value, excludeRecordId)`。Mongo 对对象数组支持 `data.子表key.子字段key` 点路径，沿用现有方法，不必新接口。

导入 Excel：整列子表仍在 `IMPORT_SKIP_TYPES` 里，不导入、也不做导入期去重。

## 7. 填报与数据管理

### 7.1 填报

`FormFillField` 里 `subform` 改为真实表格（建议独立 `FormSubform.vue`，不要在 `FormFillField` 里堆一整张表）。

- 列 = 子字段，单元格复用各类型填报控件（与 `FormFillField` 同类分支）。
- 图片列复用 `FormImageUpload`（同一上传接口、预览、格式/大小/张数限制）。表格里缩略图缩小（约 64×64），避免行被主表那种大卡片撑开；点缩略图仍走现有预览。复制行时拷贝 URL 列表，不重新上传。
- 文件列复用 `FormFileUpload`（同一上传接口、格式/大小/个数、是否可下载）。单元格里按文件名列表展示，名字过长省略。复制行时拷贝 `{ url, name }` 列表，不重新上传。只读且允许下载时仍可下载。
- 选择数据列复用 `FormDataSelect`，行为见 §7.3。单元格只显示触发条（已选标题），「显示在表单中的字段」收进触发条下方的紧凑预览，不要在格子里再铺一张大表。
- 多行文本：内容少时一行高，变多后撑高，到约 8 行高后内部滚动。
- `frozenCols > 0` 时固定左侧列（操作列若有，算在「固定」之外：先固定行操作，再固定前 N 个字段列）。
- 表底「添加」：末尾加一行空值。
- 每行：插入（在本行前插空行）、复制（在本行后插一份当前值）、删除。
- 行数到 200 时添加/插入/复制都不可用，并提示「子表单最多 200 行」。
- 无子字段时不显示添加，提示「请先在表单设计中添加子字段」。
- 新建且 `defaultRowCount > 0`：进入时生成这么多空行；用户删光后不会自动补回。编辑已有记录只显示库里的行，不再按默认行数补空行。
- 子表或主表禁用 / 编辑态不可修改：隐藏行操作和添加，单元格只读。
- 子字段下拉「其他表数据」（`optionSource: 'table_data'`）：打开添加数据 / 编辑时按源表 + 选项过滤请求一次 `POST .../records/query`，选项去重规则与主表相同。之后只在**过滤条件里引用的字段**（设计器里只能选主表字段）变化时才重查；只改本列选中值、或再添加过滤条件相同的行，不重查。同一套源表 + 过滤结果多行共用。查询时机与主表 `FormFillGrid` 对齐，不要按行临时 id 当缓存键。

主表上的选择数据**不写子表**（整表灌入见 §8）。子表自己的行内 / 整表联动见 §7.4、§7.5。

### 7.2 数据管理

- 列表把子表当成一列只读摘要（不进 `isFillable`，不能单元格编辑、筛选、排序）。空为空白；有行则每行用 ` / ` 拼子字段，行与行用 `；`。
- 添加数据、详情编辑：用同一套填报表格。
- 详情只读：同一表格只读，无增删。选择数据列只回显标题，不打开选记录。

### 7.3 子表内选择数据

对照简道云 [选择数据 §3](https://hc.jiandaoyun.com/doc/9024)。选择数据是**子字段**，不是主表字段去灌整张子表。

配置（与主表同一套对话框，范围收窄）：

| 项 | 本期 |
|---|---|
| 数据源 | 本应用已保存表单，**不含当前表**（与主表选择数据相同） |
| 显示字段 / 选择过程 | 与主表相同 |
| 过滤条件「当前表单字段」 | 主表字段 + **本子表其他列** |
| 填充规则 | 源表**主字段** → 本子表其他列。不能填主表、不能填源表的子表、不能填图片/文件/选择数据/分割线 |
| 允许新增数据源表数据 | 不做（主表选择数据也还没有） |

填报：

1. **默认可多选**。确定后：第 1 条写入**当前行**（id + 按映射填本行其他列）；其余每条在当前行后插入新行，同样写 id 和填充。总数不超过 200，多出来的不要，并提示「子表单最多 200 行」。
2. **只能单选**（弹窗按主表现在那样只定一条）当：
   - 过滤条件里出现本子表某一列（`valueType === 'field'` 且 value 是本子表字段 key）；或
   - 当前行已经有选择数据的 id（改已选记录）。
3. 过滤只引用主表字段、且当前行为空时，仍可多选。
4. 多选不做跨页 Shift 连选；勾选当前页即可。
5. 填充是拷贝：源表后来改了，已写入本行的列不跟着改。控件回显标题仍按 id 再查。
6. 复制行：拷贝 id 和本行已有值，不重新查、不重填。
7. 清空选择数据：清掉该行的 id；已填充到其他列的值**保留**（与主表选择数据改选会覆盖映射列、清控件不自动清映射列的现网行为对齐：改选覆盖映射列；只清本列不改其他列）。

不做：主表选择数据一次选多条、清空子表再整表灌入（简道云 9024 注意事项 3，另立项）。

### 7.4 行内联动

子字段走现有「取值来源 / 选项来源 = 数据联动」，弹框复用 `DataLinkageDialog`。条件右侧可选 **主表字段 + 本子表其他列**（key 全局唯一，不撞名）。触发字段类型对应规则与主表相同（见数据联动规格 §3.3）。选择数据、单选、复选列不出现数据联动。

条件右侧下拉的**展示文案**要能分清主表列和子表列（标题可能相同）。存盘仍是字段 `key`，不存这段文案：

| 选项 | 下拉显示 |
|---|---|
| 主表字段 | `当前表单.{字段标题}` |
| 本子表其他列 | `{子表标题}.{字段标题}` |

子表标题为空时用「子表单」。例如子表标题是「配件明细」、列标题是「物料编码」，条件读作「他表.编码 = 配件明细.物料编码」，不要写成「当前表单.物料编码」。整表联动条件只能选主表字段，右侧仍只出现 `当前表单.{标题}`。选择数据过滤的「当前表单字段」下拉用同一套展示。

运行时把「主表 values + 这一行」合成一份条件值再查，查询和 0/1/多条写入复用 `linkageRuntime.js`，只写**这一行这一列**。

- 画布不查。详情只读不查、不写。
- 子表禁用：仍可写入（与主表禁用字段相同）。
- 子表或该列「不可修改」且正在编辑已有记录：不写。
- 打开编辑时条件相对进入时没变：下拉只刷新选项，不改已有值；条件变了才按 0/1/多条写。
- 防抖与主表相同（约 1 秒）。每一行单独算，一行条件变了只重查这一行的联动列。只改该联动列自己的已选值、条件字段没变，不重查。

### 7.5 整表联动

配在**子表字段**上，不是子列上。对照简道云 [子表单整体数据联动](https://hc.jiandaoyun.com/doc/11259)。

取值来源选「数据联动」后，弹框（可另做 `SubformLinkageDialog`，或扩现有弹框）：

1. 联动表单（必选，本应用已保存表单，允许当前表）
2. 条件：形状与主表联动相同；右侧只能选**主表字段**或自定义值，不能选子表列
3. 赋值数据源：联动表里的一个 `subform` 字段（`sourceSubformKey`）
4. 子字段对照：当前子表列 ↔ 源子表列，至少一条。类型对应与主表联动相同。源列不能是子表、选择数据、分割线

```json
{
  "optionSource": "linkage",
  "linkage": {
    "sourceFormId": 12,
    "match": "all",
    "conditions": [
      { "key": "deviceNo", "op": "eq", "valueType": "field", "value": "deviceNo" }
    ],
    "sourceSubformKey": "parts",
    "fieldMappings": [
      { "sourceKey": "name", "targetKey": "partName" }
    ]
  }
}
```

未配完（缺表、缺条件、缺源子表、对照为空）视为未设置，不查询。

运行时（主表条件字段变化，防抖同主表）：

| 匹配到的**主表记录** | 行为 |
|---|---|
| 条件未就绪 / 0 条 | 子表写成 `[]`，不提示 |
| 1 条 | 取该记录 `data[sourceSubformKey]` 数组，按对照逐行生成当前子表行；空行丢掉；超过 200 行截到 200 并提示「子表单最多 200 行」 |
| 多条 | 子表写成 `[]`，提示 `[ 子表标题 ] 字段联动查询出多条数据`（有说明时带上说明，与主表相同） |

写入是覆盖整张子表，包括用户刚手加的行。源行没有对照列的 key 不拷。对照生成行时，某一目标列按类型转不过去则丢掉**该行**（不打断填报、不 400）。用户点保存时仍按 §6.1：已在 `values` 里的非法值整单 400。

现有 `listFormFields` 只返回 `OPTION_FIELD_TYPES`，不含 `subform`。整表联动弹框不要复用它来列「赋值数据源」。本期给该接口加可选参数（例如 `include=subform`），或另加只读接口，返回各表的 `type==='subform'` 字段及其 `fields`（子列需带 `key` `title` `type`）。主表联动、选择数据的现有下拉仍过滤掉子表，行为不变。

打开已有记录编辑：条件没变不覆盖子表；条件变了才按上表写。详情只读不查。子表「不可修改」且编辑已有记录：不覆盖。禁用：仍覆盖。

已配整表联动时，新建不再用 `defaultRowCount` 铺空行（等联动结果；条件未就绪则为空表）。

### 7.6 几种写入谁后执行

没有单独的优先级配置。同一次条件变化里按这个顺序：

1. 整表联动（若有）先覆盖子表
2. 再对每一行跑行内联动
3. 选择数据只在人点确定时写行，不自动跟条件

后触发的覆盖先写入的格子。例如整表刚填了单价，行内联动条件随即成立，会改掉该行单价。

## 8. 只登记、等后面立项

1. **主表选择数据整表填充子表**：先清空子表已有行，再按源表子字段或所选多行写入（简道云 9024 注意事项 3）。
2. **成员 / 部门 / 定位等进子表**（等控件本身完成）。
3. **显隐规则、公式、扫码加行、子表查询、快速填报、移动端**。
4. **子表 Excel 导入导出、列表按子表列筛选**。
5. **字段权限**（可新增/插入/编辑/删除）和流程节点上的子表权限。
6. **关联子表单**、子表独立集合。
7. 文本类多条取第一条、联动与选择数据的冲突配置面板。

## 9. 实现顺序（由浅入深）

1. 纯函数：允许的子类型、空行、必填、行内重复、整表对照生成行。
2. 设计器：拖入子表/子字段、选中、属性、画布表头预览。
3. 入库：`coerce` 递归、200 行、必填、跨记录 `unique`。
4. 填报：表格增删插复制；文本/数字/日期/选项/地址。
5. 子表图片、文件。
6. 子表选择数据（含多选加行）。
7. 数据管理详情只读/编辑。
8. 行内联动。
9. 整表联动。

前一步能用再做下一步。不要并行铺开。

## 10. 验收

1. 只能把 §3.1 的类型拖进子表（含图片、文件、选择数据）；子表单、分割线等拖入有提示且不插入。
2. 子表占整行；点列头编子字段，点子表空白或标题编子表。
3. 新建可加行、插行、复制行、删行；到 200 行不能再加。
4. 子表必填：0 行不能提交。子字段必填：表格里还在的每一行（含点「添加」的空行）缺必填列都不能提交。
5. 子字段「单条数据内不允许重复值」：同一记录两行相同文本/数字/选择数据 id 不能提交。
6. 子字段「不允许重复值」：另一条主表记录的子表里已有同样值，本条不能提交；数字 `0`、选择数据同一源 id 也算。
7. 禁用整表只读；不可修改在编辑已有记录时整表锁住，新建仍可填。
8. 默认行数为 2 时，新建打开有 2 行空行；子字段无必填时保存空行不入库；有必填子字段则空行要填上或删掉才能保存。
9. 固定前 1 列后，横向滚动时第一列字段仍在。
10. 数据管理列表有子表列只读摘要；详情能看到已保存的行。
11. Excel 导入模版没有子表列。
12. 复制子表单后，子字段 `key` 与原表不同，配置还在。
13. 子表图片列能上传、预览、按字段限制张数；必填时该行有其他值却没图不能提交；只读时仍可预览。
14. 子表文件列能上传、按字段限制个数和格式；允许下载时可下载；必填时该行有其他值却没文件不能提交。
15. 子表选择数据：未配过滤到本行字段且当前行为空时，一次勾选 3 条会变成 3 行，并按填充规则写入本行其他列；过滤引用了本行字段、或该行已有选中 id 时只能选 1 条。填充目标不能选主表字段。
16. 子表选择数据开了不允许重复值后，两条主表记录（或同一子表两行）不能选同一条源记录。
17. 行内联动：行内填物料编码后，该行名称自动带出；另一行互不影响。条件引用主表字段时，主表一改，各行各自重查。
18. 整表联动：主表设备编号对应他表 1 条时，子表被替换成源子表各行；0 条或多条时子表清空，多条有提示。编辑已有记录且条件没变，打开时不覆盖手改过的子表。
19. 子表下拉「其他表数据」：打开编辑会查一次源表；之后只改本列选项不再请求。选项过滤绑了主表字段时，改该主表字段才重查。
