# 表单字段公式 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 默认在 `master` 上改。未经使用者允许不开分支、不建 worktree。未经使用者要求不 commit。

**Goal:** 做成字段级「计算公式」：六类字段（单行文本/多行文本/数字/日期选择/时间选择/日期时间）可在属性里编辑公式；填写页实时算出、只读展示；提交时服务端按同一公式重算覆盖入库；支持子表行内公式与主表对子表列的聚合。

**Architecture:** 公式配置存在字段 JSON（`field.formula = { expr, refs }`），无新表无 SQL。表达式语言手写 tokenizer + 递归下降 parser（引用 `$'key'`、函数 22 个），前后端各一份实现、共用 `formula.fixtures.json` 契约测试。前端 `formulaRuntime.js` 仿联动 runtime 做指纹 watch 重算；服务端仿流水号在 persist 里 `applyFormulaValues`（coerce/merge 先丢客户端值，重算在必填/唯一/流水号之前）。

**Tech Stack:** Vue 3、Element Plus、NestJS、TypeScript、前端 `node:test`、后端 Jest。前端日期用 `dayjs`（复用 `utils/timeValue.js`）；服务端不新增依赖，日期解析/格式化手写复刻 `asDate` 语义。

**Spec:** `docs/superpowers/specs/2026-09-11-formula-design.md`

## 语法与语义（两端共同契约，实现前先读这节）

**词法**：数字 `\d+(\.\d+)?`；字符串单/双引号（不支持转义，内容不含同种引号）；字段引用 `$` + 引号 key（`$'key'`、`$'子表key.子字段key'`）；函数名与 `TRUE/FALSE` 为裸标识符 `[A-Za-z_][A-Za-z0-9_]*`（不区分大小写）；运算符 `+ - * / % == != >= <= > < ( ) ,`。引用 token 的 key 部分任意非引号字符。

**文法**：
```
expr  = cmp ;  cmp = add [ ("=="|"!="|">"|"<"|">="|"<=") add ] ;
add   = mul { ("+"|"-") mul } ;  mul = unary { ("*"|"/"|"%") unary } ;
unary = ["-"] prim ;  prim = number | string | bool | ref | call | "(" expr ")" ;
call  = ident "(" [expr { "," expr }] ")" ;  ref = "$" string
```

**AST**：`{kind:'num'|'str'|'bool'|'ref'|'call'|'binary'|'unary', ...}`；ref 节点存 `path: string[]`（按 `.` 拆）。

**运行时求值**：
- 引用解析由调用方注入：主表上下文 `len1 → values[key]`、`len2 → values[sub] 为行数组时取列（数组）`；行内上下文 `len1 → row[key] ?? parent[key]`、`len2 → undefined`。
- 算术：`- * / %` 先转数字（number→本身，boolean→0/1，日期字符串→毫秒，其余→undefined，结果是 undefined 一路传染）；除/取模 0 → undefined。`+` 两边只要有一边是字符串就做拼接（空值当 ''），否则走数字加。
- 比较 `> < >= <=`：两边都能转数字按数字，否则两边都是字符串按字典序，否则 undefined；`==`/`!=`：boolean 转数字后数字比较，否则 `String(a)===String(b)`（两个都空算相等）。
- 真值：`undefined/null/false/''/0/NaN` 为假，其余为真。
- 函数语义见规格 5.3；`IF` 只算用到的分支；聚合函数参数摊平后只留有限数字（空值跳过），全空返回 undefined。
- `TODAY()/NOW()` 用注入的 `now`（不许直接取系统时间），fixtures 里不出现这两个函数（另测）。

**结果归一化**（写回字段值前）：`number` → 有限数字否则空；`input/textarea` → `String(value)`；`date` → `YYYY-MM-DD`；`time` → `HH:mm:ss`（前端按 `field.format` 走 `formatTimeFieldValue`）；`datetime` → ISO 字符串。前端 datetime 控件无 value-format，既有存量值也是 ISO 字符串，写 ISO 字符串两端一致。

- [ ] **Step 4: 实现 parser.ts / functions.ts / evaluator.ts**

parser.ts 要点：

- tokenizer 逐字符扫描，记录行号（遇 `\n` +1）与列号；字符串未闭合、非法字符 → `syntax` 错误带行列。
- `$` 后必须是引号字符串，否则 `syntax`；ref 的 path 按 `.` 拆段，段为空 → `syntax`。
- 递归下降按上文文法；多余 token 未消费 → `syntax`；未知标识符不是函数（后面没有 `(` 且不区分大小写后不是 true/false）→ `unknown-function`。
- call 节点：函数名查 `FORMULA_FUNCTIONS`（大小写不敏感）；不存在 → `unknown-function`；参数个数不在 minArgs/maxArgs → `arity`。
- 解析成功收集 refs：按 ref 节点出现顺序去重，`path.join('.')`。

functions.ts 要点：

- `FORMULA_FUNCTIONS` 22 条定义（name/category/minArgs/maxArgs/summary/参数类型表）。
- 日期工具（不依赖 dayjs，语义与前端 `timeValue.js` 的 `asDate` 对齐）：
  - `parseDateLikeToMs(v)`：`Date` 实例 → getTime；`YYYY` / `YYYY-MM` / `YYYY-MM-DD` → 本地零点（`new Date(y, m-1, d)` 分量构造，不要 `Date.parse`——`Date.parse('2026-08-22')` 按 UTC，两端会差 8 小时）；`YYYY-MM-DD HH:mm[:ss]` 与 `YYYY-MM-DDTHH:mm:ss` → 本地；`HH:mm[:ss]` → 挂在 1970-01-01；数字直接返回；其余 → null。
  - `formatMs(ms, fmt)`：按 `YYYY MM DD HH mm ss` 记号替换（用本地分量），只支持这 6 个记号；`startOfDayMs(ms)`。
- 函数实现按 Global 语义一节；聚合函数收到数组参数摊平、保留转数字成功的值。

evaluator.ts 要点：

- `evaluateAst` 后序遍历；错误（含引用解析出的 undefined 传染）返回 `{ ok:false }`；`IF` 先算条件再只算命中分支。
- `inferType`：按参数类型表检查每个实参（实参类型递归推断；ref 用 `typeOf` 回调；`unknown` 永远放行）；二元运算按上文规则；根类型即返回值。
- `applyFormulaValues`：
  1. `flattenFields`（复用 `./flatten-fields`）收集 `formula?.expr` 的字段；行内公式字段 = 有父 subform 的（用 `fields` 树直接遍历 subform.fields）。
  2. 拓扑排序：公式字段 → 其 refs 命中其它公式字段则连边；有环（schema 校验兜底失败）→ 跳过并记 warning。
  3. 逐个求值：主表公式 resolve 见上文主表上下文；行内公式对 `data[subKey]` 每行求值（`row[key] ?? data[key]`）。
  4. 结果经 `normalizeFormulaValue(field, value)`（date→`YYYY-MM-DD`、time→`HH:mm:ss`、datetime→`new Date(ms)`、number→有限数字、input/textarea→`String`）写回 `data[key]` / 行对象；求值失败不写、收集 warning `[标题] 公式计算失败：<message>`。
- 返回 warnings 数组。
