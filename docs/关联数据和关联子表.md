# 关联

数据之间是真的有某种联系了



## 关联数据

一个表单可以关联别的表，也可以关联自己

- 关联别的表，典型的就是工厂和工人之间的关系

- 关联自己，典型就是构建层级关系（树形）

树形关系表的数据，在简道云里**没有**直接能绑的组件。可以通过设置**数据联动**的条件，加多个**下拉框**来实现。

> 父级下拉框只需要设置关联其他表，选好表即可
>
> 子级设置联动规则：树形表的父级字段 = 父级下拉框选定的值
>
> 孙级设置联动规则：树形表的父级字段 = 子级下拉框选定的值
>
> 这样就可以一级一级的选择下去

一个表单里使用了**关联数据**，那它就是个**子表**，所关联的表就是**主表**

关联数据组件也要有**显示在表单中的字段**的设置，功能跟**选择数据**类似，在表单里显示

## 关联子表

准备两张表：**工厂表**和**人员表**

工厂表有两个字段：**工厂编码**、**工厂名称**

人员表有两个字段：**工人名**、**工人编号**

工厂表里添加**关联子表**组件。简道云添加时会弹框，是选择从已有关联表选择，还是从空白新建。**我们简化一下：只有从已有关联表选择**。可以供选择的表单，就是表单里有**关联数据**组件，并且配置关联**工厂表**的那些表单。

工厂表新增时，就只能看到工厂编码、工厂名称两个字段，但查看详情时，**除了**会看到这两个字段以外，还会看到**关联自己**的那些表单的数据，以**table**格式查看，**可翻页**

> 在主表里添加关联子表，是为了可以在主表详情里看到哪些表里的哪些数据，关联了正在查看的这条主表的数据，也就是说主表数据详情里要查看对应的子表数据
>
> 简道云的设计是，在画布右侧，**查看/编辑主数据时**可以设置可新增，可删除，可编辑等等功能，我们做简化：**暂时不做这些选项和对应的功能**。想新增，编辑，删除子表数据，去到对应的**子表**去执行这些动作，比如这里的**人员表**。
