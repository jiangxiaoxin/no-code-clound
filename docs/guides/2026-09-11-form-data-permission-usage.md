# 表单谁能看见、数据看哪些行

日期：2026-09-11  
对照测试：`docs/testcases/2026-09-11-form-data-permission-test-cases.md`

应用后台【使用范围】只决定谁能进这个应用。进了之后，每张表还可以自己再收一档。

## 默认

- 能进应用的人，左侧树里每张表都在。
- 【数据管理】普通使用人只看见与自己相关的行：自己填的；流程表再加上派给自己批过、正在批、抄送给自己的。
- 所有者和配置名单始终能看见所有表、所有行。

## 在哪改

打开这张表的设计页 → 顶栏【表单发布】→【谁可以看】→【保存设置】。

1. **这张表谁能看见**：名单为空就不限制。加了部门 / 角色 / 人员之后，普通使用人必须命中才看得见这张表。选部门不含下级。
2. **数据范围**：与自己相关 / 仅本人创建 / 本部门 / 全部。

看不见的表不会出现在树里；硬开网址会提示表单不存在。

没有应用使用权的审批人不要到【数据管理】里找单，走首页【我的待办】看派给自己的那一条。
