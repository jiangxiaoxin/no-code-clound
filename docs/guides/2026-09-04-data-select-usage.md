# 选择数据使用说明

日期：2026-09-04  
范围：调色板 **选择数据** `data`（主表、标签页内）。子表里的选择数据格子固定显示「已选择」，没有「显示在表单中的字段」。  
对照测试：`docs/testcases/2026-08-30-subform-test-cases.md` §9（子表）；主表行为见下文。

本文说明**格子里显示什么**。怎么配数据源、填充、选择过程，仍按设计器右侧属性操作。

---

## 1. 格子里显示什么

选择数据**没有**「显示字段」这一项。那是 **关联数据** `relate` 才有的（例如「所属工厂」选「工厂名称」，格子就是工厂名称）。

主表选择数据收起态（添加数据、编辑、详情里那个像下拉的格子）按下面取字：

| 「显示在表单中的字段」 | 格子里写什么 |
|---|---|
| **没配** | 「已选择」 |
| **配了** | 按勾选**顺序**，取**第一条有值**的列 |

格子**下方**的小卡片，才是把勾上的字段一行一行写成「字段名：值」。卡片顺序和勾选顺序一致，但**不会**改格子里那一行字——格子只看第一条有值的。

填充到其他字段的值（例如拷到「选择出来的工厂」）是另一列自己的内容，不决定这个格子写什么。

### 例子

人员表有一个选择数据，数据源是工厂表。「显示在表单中的字段」勾了：

1. 工厂编码  
2. 工厂名称  
3. 创建人  

选中「二号厂」后：

- **格子**：`F002`（第一条是工厂编码）
- **下方卡片**：工厂编码：F002；工厂名称：二号厂，改名字；创建人：管理员姓名

同一条记录上的关联数据「所属工厂」若「显示字段」选了工厂名称，格子就是「二号厂，改名字」。两个控件可以并存，显示规则不同。

想让选择数据的格子也显示工厂名称：设计器点这个选择数据 → 「显示在表单中的字段」→ 把 **工厂名称排到第一位**（或只勾工厂名称）→ 保存后再打开详情。

## 2. 和关联数据怎么区分

| | 选择数据 `data` | 关联数据 `relate` |
|---|---|---|
| 干什么 | 挑一行来**拷**值 | **指向**那一行 |
| 格子用哪一列 | 「显示在表单中的字段」的第一条有值列；没配则「已选择」 | 单独的「显示字段」 |
| 源表改了名称 | 格子按 id 再查，能跟进；**填充出去的字段还是旧拷贝** | 显示字段刷新跟进；填充出去的同样不跟 |

子表里的选择数据没有「显示在表单中的字段」，格子始终是「已选择」。
