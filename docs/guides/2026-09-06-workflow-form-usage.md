# 流程表单使用说明

日期：2026-09-06  
范围：建表时选【流程表单】，在【流程设计】画布上配审批，用【添加数据】提交，在首页或应用里处理待办。  
对照测试：`docs/testcases/2026-09-06-workflow-form-test-cases.md`

本文按界面按钮写。流程不是调色板里的控件。

---

## 1. 怎么建成流程表单

在应用里点 ＋ →【新建表单】，名称下面有「表单类型」：

- **普通表单**：填完点【保存】就是正式数据。
- **流程表单**：填完点【提交】进入审批，必须先启用一版流程才能填。

建错成普通表单时，在左侧表单树的 ⋯ 菜单点【转为流程表单】。已有数据会记成已通过，启用流程之前不能再填。**流程表单不能转回普通**，建错了只能删表再建。

---

## 2. 怎么画流程

打开这张表的设计页，顶栏多出【流程设计】（普通表单没有这一项）。

1. 打开时自动有「流程版本 (V1)」，画布上已经有一个不能删的【开始】。
2. 从左侧拖【审批节点】、【分支节点】、【抄送节点】、【结束节点】，用线连起来。
3. 点开始、结束或审批节点，右侧都能改节点名称。开始节点还有开关「流程终止后是否可以修改后重新提交」，默认打开；关掉并【保存并启用】后，已通过和已驳回都不能再改、不能再交。审批节点另外写找谁批、或签还是会签、哪些字段可改（默认全部只读，要改必须点成可编辑）、同意时意见要不要必填。转交、加签在「审批操作」里勾，默认关。
4. 【抄送节点】挂在开始、审批或分支旁边：从这些节点再拉一条线到抄送，原来那条主路不用改。抄送不能再往外连线。右侧选抄送人（和审批同一套四种来源），字段只有「不可见」和「简报」；没勾不可见的，被抄送的人打开后只能看。可以不配人，仍能启用。
5. 点从分支拉出来的线：配条件（例如请假类型 = 事假），或勾「其他情况」。可以上移下移调整顺序。连到抄送的线不用配条件。
6. 点【保存】只写入当前正在看的这一版，不会马上给填报用。
7. 点【保存并启用】会先弹出确认；确定后先保存再启用当前这一版。若已经有启用中的版本，那一版会变成设计中。
8. 顶栏左侧点版本名称打开下拉：可切换版本、【添加新版本】（复制当前选中的图）、【管理已有版本】。也可以在管理弹窗里对某一版点【启用流程】（要先保存）。校验通过后这一版变成启用中（绿色）。同一时刻最多一版启用。启用中的画布只能看，不能改、不能删，也没有【停用】；要换流程就启用另一版，原来那版变回设计中。

从来没有启用过时，工作台提示还没有配置流程，填不进去。审批中的单仍按提交当时那张图走，不跟着你切启用版而变。

## 3. 三种审批人

在审批节点右侧选一种或几种，系统会并到一份名单里，同一个人只收到一条待办：

| 怎么选 | 谁会收到 |
|---|---|
| 指定人员 | 你勾上的人 |
| 指定角色 | 这个角色下的启用用户。默认勾着「限定与发起人同部门」：只有和发起人同一部门的人能收到。取消勾选时会提示：该角色下所有部门的人都会收到待办 |
| 表单内人员字段 | 填报时人员单选 `member` / 人员多选 `member-multiple` 里选中的人 |

或签：名单里任一人【通过】即可往下走，其他人的待办取消。会签：每个人都必须【通过】；任一人【驳回】，整节点驳回。

---

## 4. 【添加数据】怎么交

有一版处于启用中时，底部是【保存草稿】和【提交】，没有普通的【保存】。

- 还没启用过任何版本：顶部写「这张表单还没有配置流程，暂时不能填报」，两个按钮都不会写出数据。【数据管理】的【新增】同样拦。
- 【保存草稿】：【数据管理】能看到「草稿」，别人用选择数据 `data` / 关联数据 `relate` 挑不到。
- 【提交】成功：提示「已提交，等待「部门审批」」这种带节点名的句子；如果流程直接结束，提示「已提交并通过」。

【数据管理】里审批中的行不能改、不能删。草稿 / 已驳回 / 异常只有发起人能改。已通过后，只有原发起人能在【数据管理】点【编辑】再【提交】，会按**此刻启用中**的图重新走一遍；首页【我发起的】里已通过的只能看。若开始节点关掉了「流程终止后是否可以修改后重新提交」，已通过和已驳回都变成只能看。

---

## 5. 四个入口怎么用

首页产品名旁边有【我的应用】【我的待办】【我发起的】【我处理的】【抄送我的】。【我的待办】会显示还没处理的条数；【抄送我的】没有数字。

进到某个应用后，左侧应用名下面、搜索框上面还有同样四行，只看**本应用**的单。本应用一张流程单都没有时，四行仍在，点进去是空的。

| 入口 | 看见什么 | 抽屉底部 |
|---|---|---|
| 我的待办 | 派给我、还没处理的 | 意见框 +【同意】【驳回】【退回至上一审批节点】【退回至发起人】；右侧勾了才有【转交】【加签】。第一个审批没有上一节点时，没有【退回至上一审批节点】。退回发起人后这条底部是【提交】，没有同意/驳回 |
| 我发起的 | 我交过的（含草稿、审批中、已驳回、异常） | 【保存草稿】【再次提交】【撤回】；异常时还有【重试】。已通过只读。开始节点关掉「终止后再交」时，已驳回也只读 |
| 我处理的 | 我批过的 | 只读 |
| 抄送我的 | 流程离开某个节点时抄给我的 | 只读，没有意见框，没有【通过】【驳回】 |

抄送挂在开始上：点【提交】就发。挂在审批上：这个节点【同意】才发，【驳回】【撤回】不发。没配抄送人也能启用，交单后进度会写「没有可抄送的人」。

没有进这个应用权限的人，只走首页，不能进该表的【数据管理】。数据被删掉后，卡片会标「数据已删除」，还能在【流程】页签看进度，不能改。

打开抽屉默认是【表单】页签，表单铺满；要看小流程图和审批记录，点【流程】。底部按钮始终在抽屉最下面，不跟着页签走。

【同意】【驳回】只出现在【我的待办】，不要到【数据管理】里找这两个按钮。待办里还可能看到转交、加签、两种退回；退回至发起人后，发起人在【我的待办】改完点【提交】，单据仍是审批中，不是已驳回。
