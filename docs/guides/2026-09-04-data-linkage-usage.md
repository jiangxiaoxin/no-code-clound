# 数据联动使用说明

日期：2026-09-04  
范围：**主表**（含标签页 `tabs` 内字段）上，通过「取值来源 / 选项来源 = 数据联动」按条件从他表自动填值或刷新下拉选项。  
对照设计：`docs/superpowers/specs/2026-08-27-data-linkage-design.md`  
对照测试：`docs/testcases/2026-08-27-data-linkage-test-cases.md`

本文说明**怎么配、填报时怎样生效、和选择数据 / 下拉他表数据的区别**。不写逐步测试编号。

子表里的**行内联动**、**整表联动**是另一套（配在子表列或子表标题上），见 `docs/testcases/2026-08-30-subform-test-cases.md` §10、§11，下文 §8 只作指向。

---

## 1. 数据联动干什么

在当前表单里填了某些字段（**条件字段**）后，系统**自动**去另一张已保存的表单查记录，把匹配结果写到**当前这一列**：

- 文本、数字、日期时间、图片、文件：直接写入该列的值；
- 下拉单选 / 下拉多选：刷新选项，必要时自动选中；
- 人员 / 部门 / 地址：写入 id 或地址结构（规则见各控件说明）。

**人不用**像「选择数据」那样打开弹窗勾一行。典型例子：奖金申报里填「员工编号」，「姓名」「手机」「部门」自己带出来。

每个要自动带出的列都要**单独配一次**联动：联动表和条件可以相同，只改「触发以下联动」里选源表哪一列。

---

## 2. 和另外三种能力不要混

| 能力 | 人做什么 | 库里存什么 | 源表后来改了，已保存的记录 |
|---|---|---|---|
| 下拉「其他表数据」 | 自己在下拉里挑 | 选中的**字段值**（文本/数字），不是记录 id | **不会**跟着变 |
| **数据联动** | 填条件字段，系统等结果 | 当前列自己的值（文本、选项 value、图片 url 等） | **不会**跟着变（联动不是关联） |
| 选择数据 `data` | 弹窗勾一条，可填充多列 | 本列存源记录 id（只为回显）；被填充列存**拷贝值** | 格子按「显示在表单中的字段」第一条有值的列回显（没配则「已选择」）；填充列仍是旧拷贝。详见 `docs/guides/2026-09-04-data-select-usage.md` |
| 关联数据 `relate` | 弹窗选一条建关系 | 源记录 id，表示关联 | 格子用单独的「显示字段」，源表改名刷新跟进 |

怎么选：

- 只要**下拉选项**、人来选，尤其省→市→型号级联：用下拉 **其他表数据 + 选项过滤**。
- **编号带出姓名**等自动填一格：用 **数据联动**。
- 人选一行、**拷贝多个字段**到本表：用 **选择数据 + 填充规则**。
- 要**长期指向**那条记录、改名能跟进：用 **关联数据**（显示规则见 `docs/guides/2026-09-04-data-select-usage.md`）。

## 3. 哪些字段能配

### 3.1 主表 / 标签页内

| 调色板名称 | type | 属性面板入口 |
|---|---|---|
| 单行文本、多行文本、数字 | `input` / `textarea` / `number` | **取值来源** → 自定义 / **数据联动** |
| 日期选择、时间选择、日期时间 | `date` / `time` / `datetime` | 同上 |
| 图片上传、文件上传 | `image` / `file` | 同上 |
| 地址选择 | `address` | 同上 |
| 人员单选、人员多选 | `member` / `member-multiple` | 同上（人员多条规则见 `docs/guides/2026-09-01-member-select-usage.md` §6） |
| 部门单选、部门多选 | `dept` / `dept-multiple` | 同上（另有「当前用户所在部门」，与联动不同） |
| 下拉单选框、下拉多选框 | `select` / `select-multiple` | **选项来源** → 系统字典表 / 其他表数据 / **数据联动** |

### 3.2 不能在这里配「数据联动」

| 类型 | 原因 |
|---|---|
| 单选框 `radio`、复选框 `checkbox` | 只有「选项字典」，无取值/选项来源 |
| 选择数据 `data` | 用「数据源 + 填充规则」 |
| 登录人姓名 / 登录人部门 | 只读，不入库 |
| 流水号 `serialNumber` | 保存后生成，不当联动触发目标 |
| 分割线、标签页、子表单容器 | 不是数据列 |

## 4. 设计器里怎么配（示例）

以「奖金申报」的 **姓名** 为例，从 **员工档案** 带出（完整表结构见联动专项用例文首）。

1. 打开 **奖金申报** 设计器，点字段 **姓名**。
2. 右侧 **取值来源** 选 **数据联动** → 点 **设置数据联动**（弹框标题「数据联动设置」，可拖标题栏）。
3. **联动表单**：选 **员工档案**（须先保存过该表；可搜索表名）。
4. **条件**：点「添加过滤条件」——左侧选员工档案的 **员工编号**，中间 **等于**，右侧选 **当前表单字段** → **员工编号**。  
   - 多条条件时，上方可选 **所有** / **任一** 满足。  
   - 条件右侧可在「当前表单字段」与「自定义值」之间切换（悬停图标）。  
   - 至少配 **一条完整条件**，否则不能保存为「已设置」。
5. **触发以下联动**：左侧是当前列「姓名」（只读）；右侧选员工档案的 **姓名**（类型须对得上，见 §5.3）。
6. 确定 → 按钮变为 **已设置数据联动**，右侧出现清除圆圈 → 再点设计器 **保存**。

手机、部门、奖金基数等：重复以上步骤，**条件相同**，只改「触发以下联动」里选的源表字段。

**清除**：点「已设置数据联动」旁的清除 → 确认「确定删除数据联动？」→ 配置删掉，来源仍停在「数据联动」，按钮回到「设置数据联动」。

**画布**：配了联动的格子只显示占位（如「请输入」），**不会**查出「张三」。真实查询只在 **添加数据 / 编辑抽屉** 里发生。

## 5. 填报时怎么生效

### 5.1 何时查询

- 条件里引用的 **当前表单字段** 发生变化后，约 **1 秒** 防抖后再查（首次打开新增/编辑会立刻判一次）。
- 条件里还有空着的必填项（例如员工编号还没填）时：**不查**，目标列当 **0 条** 处理，**不弹**「查询出多条」。
- **设计器画布**、**数据管理列表里点单元格改**：**不跑**联动。要验证带出，请用添加数据或详情编辑。

### 5.2 查到 0 / 1 / 多条时（文本、数字、日期时间）

| 条数 | 行为 |
|---|---|
| **0 条** | 目标列**清空**，无提示 |
| **1 条** | 写入源表对应字段的值 |
| **多条** | **不写入**（清空目标列），页面提示：`[ 字段标题 ] 字段联动查询出多条数据`（有字段说明时会带上说明） |

已保存的记录里存的是**当时带出来的字**，不是员工档案的记录 id。源表后来改了姓名，**不会**自动改历史申报单。

若业务上可能一对多、需要人选一条：应把目标列做成 **下拉单选**，不要用单行文本硬扛多条。

### 5.3 下拉单选 / 下拉多选（选项来源 = 数据联动）

| 条数 | 行为 |
|---|---|
| **0 条** | 选项清空，当前选中清空 |
| **1 条** | 选项只有这一条，**自动选中** |
| **多条** | 选项为去重后的若干条，**不自动选**，等人自己点；**不弹**「查询出多条」 |

例：省份填「浙江」后，城市下拉里出现杭州、宁波，需自己选一个。

「触发以下联动」里源表字段类型须与当前下拉能对应（如源表「城市」是单行文本，才能给下拉当地选项来源）。

### 5.4 图片、文件

- **0 / 1 条**：与文本类似，写入 url（图片）或 `{ url, name }` 列表（文件）。
- **多条**：收集全部文件的 url，若不超过该列配置的最多张数/个数则全部写入；超过则清空并提示超量，**不弹**「查询出多条」。

### 5.5 禁用、不可修改

| 设置 | 新增 | 编辑已有记录 |
|---|---|---|
| **是否禁用** | 格子灰、人不能点，**联动仍可写入** | 同上 |
| **是否可修改** | 可联动写入 | 打开编辑后**不再**被联动改掉已有值；条件没变时，下拉只刷新选项列表，**不改**已选文字 |

详情 **只读**：不查询、不写值。点 **编辑** 后才按上面规则跑。

未打开的标签页里，联动和必填一样**仍然生效**（组合用例有覆盖）。

## 6. 条件与类型要注意什么

- **联动表单**只能是本应用里**已保存**的表（可含当前表自己，用于本表内引用）。
- 条件左侧除业务字段外，还可选源表的 **创建人 / 更新人 / 创建时间 / 更新时间**；一般业务联动用业务字段即可。
- **触发字段**与当前字段类型要匹配：数字对数字，日期对日期；单行文本可对应源表的单行、多行、单选、下拉单选等（以设计器下拉为准，对不上的不会出现）。
- 切换取值来源 / 选项来源时，会清掉另一套配置（与字典、其他表数据互斥相同）。

## 7. 常见误用

1. **在画布上看不出联动结果** → 正常，去添加数据里测。  
2. **条件字段还空就 expect 报错** → 应按 0 条静默清空。  
3. **员工编号重复两条档案** → 文本类目标列会清空并提示多条；测完删掉重复数据。  
4. **以为联动会更新历史单据** → 不会，只是当时拷贝值；要跟随源表改名用关联数据（未实现）。  
5. **和选择数据混用** → 选择数据要人勾行、可一次填充多列；联动只服务**当前这一列**、不存「关系」。  
6. **在列表单元格里改编码希望带出姓名** → 列表内联编辑不跑联动。  
7. **人员单选多条记录** → 按**记录条数**算多条，不是按人数；两条记录同一人也会提示多条（见人员使用说明）。

## 8. 子表里的联动（另文）

| 场景 | 在哪配 | 说明 |
|---|---|---|
| **行内联动** | 点子表**某一列** → 取值/选项来源 = 数据联动 | 每一行单独查、只写该行该列；条件可选主表字段或**本子表其他列**（下拉里显示「订单明细.xxx」） |
| **整表联动** | 点**子表标题**（不要点某一列）→ 取值来源 = 数据联动 | 主表条件命中后**整张子表**换成源表子表多行 |

操作步骤与用例： `docs/testcases/2026-08-30-subform-test-cases.md` §10、§11。
