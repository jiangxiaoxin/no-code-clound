# 部门单选 / 部门多选手工测试用例

建议先读本目录 [README.md](./README.md)，做完组合冒烟再跑本专项。部门和标签页 / 子表 / 人员「按部门字段」叠在一起的步骤见组合用例 `2026-08-31-complex-form-manual-tests.md` **§6**。

日期：2026-09-02  
用途：对照界面逐步点选。每条右侧「结果」列可记通过 / 失败。  
范围：主表和子表里的部门单选 `dept`、部门多选 `dept-multiple`：设计、选部门弹框、必填、列表名称、导入跳过、数据联动。不含关联数据 `relate`、跨应用。调色板中文名与 `type` 对照见 [README.md](./README.md)。

---

## 0. 冒烟

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| S-01 | 打开表单设计，拖入部门单选 `dept`、部门多选 `dept-multiple` | 能放进主表；画布是禁用预览，不是灰掉的普通下拉 | |
| S-02 | 保存后添加数据：部门单选点开，选一个部门，确定 | 控件上是部门名称标签 | |
| S-03 | 部门多选选两个部门，保存 | 成功；详情里两个名称都在 | |
| S-04 | 数据管理 | 两列显示部门名（多选用顿号）；**不能**单元格内联编辑 | |

## 1. 设计器

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| D-01 | 选中部门单选 | 紧挨必填有**可选范围**（全部 / 自定义）和**取值来源**（自定义 / 当前用户所在部门 / 数据联动）。还有标题、占位、必填、宽度、tips、禁用、可修改 | |
| D-04 | 可选范围改成自定义，点设置可选范围 | 弹框可拖拽，部门树有复选框。勾一个父级，下级也勾上。确定后按钮变成「已设置可选范围」 | |
| D-05 | 点清除 → 确定 | 回到「设置可选范围」；范围仍是自定义 | |
| D-06 | 取值来源改成当前用户所在部门 | 不出现「设置数据联动」 | |
| D-07 | 取值来源改成数据联动，点设置数据联动 | 与人员相同的联动弹框；源字段只能选部门单选 | |
| D-02 | 把部门单选拖进标签页 `tabs` 的某个 pane | 能放进去 | |
| D-03 | 把部门单选、部门多选拖进子表单 `subform` | 都能成为一列 | |

## 2. 填报弹框

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| F-01 | 添加数据，点部门单选 | 弹框标题「选择部门」，可拖拽；顶部「未选择部门」；下面是组织部门树。停用部门不出现 | |
| F-02 | 点一个部门，再点确定 | 点节点后弹框不关，已选区出现该部门；确定后关闭，控件上是名称标签 | |
| F-03 | 再打开，点另一个部门，确定 | 单选只保留后选的那一个 | |
| F-04 | 点标签上的关闭 | 去掉该部门，不打开弹框 | |
| F-05 | 部门多选：树有复选框。勾一个有下级的父级，再确定 | 父级和下级都出现在已选区和控件上 | |
| F-06 | 再打开，取消父级勾选 | 下级一起取消；确定后控件上没有它们 | |
| F-09 | 可选范围=自定义且勾了「研发」。添加数据打开部门单选 | 树里只有研发及其下级，没有财务等范围外部门 | |
| F-10 | 自定义范围一个部门都不勾就保存字段。添加数据点开 | 正文「没有可选择的部门」 | |
| F-11 | 取值来源=当前用户所在部门。登录人有部门且该部门在可选范围内。打开添加数据 | 控件上已是登录人部门，可改可清。清掉后同一轮不再自动填回 | |
| F-07 | 组织里没有启用部门 | 正文「没有可选择的部门」 | |
| F-08 | 部门单选必填，不选就保存 | 拦住「请填写「…」」 | |

## 3. 列表、导入、联动

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| L-01 | 保存后看数据管理 | 显示当前部门名，不是纯 id | |
| L-02 | 管理后台改该部门名称，刷新列表 | 格子跟新名字 | |

## 4. 子表与人员「按部门字段」

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| C-01 | 子表一行里选部门单选和人员单选，保存 | 详情该行都在；列表子表摘要能看到部门名和人名 | |

## 不要测

- 关联数据 `relate`、关联子表单 `relate-subform`。
- 按部门列做复杂筛选 / 排序、导入部门列、跨应用。
- 把人员「按部门字段」配到部门多选 `dept-multiple` 上（界面只列出部门单选 `dept`）。
