# 人员单选 / 人员多选手工测试用例

建议先读本目录 [README.md](./README.md)，做完组合冒烟再跑本专项。人员与标签页 / 子表 / 联动叠在一起的步骤见组合用例 `2026-08-31-complex-form-manual-tests.md` **§6**。

日期：2026-08-31  
用途：对照界面逐步点选。每条右侧「结果」列可记通过 / 失败。  
对照：`docs/superpowers/specs/2026-08-31-member-select-design.md`  
范围：主表人员单选 `member`、人员多选 `member-multiple` 的设计、选人弹框、必填/禁用/可修改、列表姓名、导入跳过、数据联动。不含部门选择 `dept`、子表内人员、按人员列做复杂筛选、跨应用。调色板中文名与 `type` 对照见 [README.md](./README.md)。

---

## 和界面有关的实现细节

- 调色板名称可能是 **成员选择** 或 **人员单选** / **人员多选**，字段 `type` 分别是 `member`、`member-multiple`。和登录人姓名 `currentUser` 不是同一个控件：登录人只读、不入库；人员选择存用户 id。
- 属性紧挨必填：**可选范围**（全部 / 自定义 / 按部门字段）、**取值来源**（自定义 / 数据联动）。没有「设计器里预选默认人」。
- 自定义范围：按钮「设置可选范围」；配完变为「已设置可选范围」。右侧清除会弹出标题 **清除**、文案 **确定清除已设置的可选范围？**。弹框标题 **设置可选范围**，可拖拽。顶部按部门、角色、人员显示已选项，可点删除。下方三个 Tab 勾选；人员 Tab 有搜索（失焦或回车才查）和分页，不是一次列出全部人员。切走再切回勾选仍在。
- 按部门字段：下拉只列出当前表（含标签页内部）的 **部门选择** 字段。本期部门选择控件未完成，表上通常没有可选字段，下拉为空，占位 **请先添加部门选择字段**。该选项仍要出现，但**不要**把「改部门后清人」当本期功能测。
- 填报点控件空白打开弹框，标题 **选择人员**，约 720px，可拖拽。顶部是已选区：有人选时显示标签和删除图标，无人时 **未选择人员**。左侧 **部门 / 角色 / 人员**；按部门字段时没有「角色」。中间列没有条件时右侧不查人员：未点部门显示 **请选择部门**，未点角色显示 **请选择角色**，人员 Tab 搜索在中间，占位 **按姓名 / 用户名搜索**，未输入显示 **请输入姓名或用户名搜索**。有条件后右侧分页，每页固定 10 条。单选、多选底部都有取消和确定：点一行只改弹框内选中态，**不关**弹框；点确定才写入并关闭。已选区删除只改草稿。取消不改控件上的人选。
- 自定义三个名单都空时，弹框正文 **没有可选择的人员**。范围内无人时列表提示 **暂无人员**。
- 控件上每人一个标签，全部展开不省略。清除用人名旁的关闭图标，只去掉该人，不打开弹框。未选时占位默认 **请选择**。
- 库里存用户 id（单选一个正整数，多选整数数组）。列表、详情按查询返回的姓名显示；多人用 **顿号** `、` 拼接。改管理后台 `displayName` 后刷新即跟进。用户已从库里消失则显示 **已删除**。
- 选人弹框只请求 `GET /api/org/departments|roles|users`（登录即可）。不要走 `/admin/users` 等管理接口。停用用户不会出现在弹框里。
- 联动：人员单选按**匹配记录条数**，多于 1 条则清空并提示 `[ 标题 ] 字段联动查询出多条数据`。人员多选 `pageSize: 100`，按记录收集 id、去重保序，不截人数、不弹多条。他表字段树（「其他表数据」）里**不出现**人员字段。联动写入可以带出当时不在可选范围里的人；手选仍受范围限制。新增/编辑里带出的人应显示姓名；只有用户确实不在库里才显示 **已删除**。
- 列表不可单元格内联编辑。导入模版和导入过程都跳过这两列。人员多选不做列表筛选。

## 0. 准备

1. 登录本系统，打开一个**自己的应用**。
2. 管理后台确认至少有：
   - 两名 **启用** 用户（下文称「甲」「乙」），能看出不同的显示名。
   - 一名 **停用** 用户（下文称「丙」）。
   - 至少一个启用部门、一个启用角色；甲、乙尽量分在不同部门或不同角色，方便测自定义并集。
3. 准备一个**没有**用户管理 / 部门管理权限的普通登录账号，后面测选人弹框不要 403。
4. 每张表拖完字段立刻点设计器 **保存**。

## 2. 设计器

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| D-01 | 选中负责人。可选范围三个按钮：全部、自定义、按部门字段。取值来源：自定义、数据联动 | 没有「预选默认人」；公共项仍有标题、占位、必填、宽度、tips、禁用、可修改 | ok |
| D-02 | 可选范围改成自定义 | 出现「设置可选范围」（尚未配置时无清除图标） | ok |
| D-03 | 点设置，弹框标题「设置可选范围」，可拖标题栏。默认在「部门」Tab。勾一个部门后切到「角色」再勾一个角色，再切回「部门」原先勾选仍在。弹框上方出现对应部门、角色标签。确定 | 按钮变为「已设置可选范围」，右侧有清除图标 | ok |
| D-12 | 再点设置，切到「人员」。名单带分页（默认 20 条/页）。输入姓名或用户名后失焦或回车 | 这时才按关键词查；输入过程中名单不变。不是一次列出全部人员 | ok |
| D-13 | 勾一名人员后，弹框上方「人员」出现该人标签。点标签删除，再翻页回来看该人。点取消关闭弹框 | 标签消失；列表里取消勾选。取消后字段配置仍是 D-03 勾过的部门/角色，不含这名人员 | ok |
| D-04 | 点清除 → 取消 | 配置还在 | ok |
| D-05 | 再点清除 → 确定（文案「确定清除已设置的可选范围？」） | 回到「设置可选范围」；范围仍是自定义 | ok |
| D-06 | 可选范围改成按部门字段 | 部门字段下拉为空，占位「请先添加部门选择字段」。不要去拖未完成的部门选择 `dept` 来凑 | ok |
| D-07 | 取值来源改成数据联动，点设置数据联动 | 与其它文本字段同一套弹框；触发字段只能选源表的人员单选（当前是单选） | ok |
| D-08 | 配完联动后看画布标题旁 | 有联动图标；画布仍不查出具体人名 | ok |
| D-09 | 取值来源改回自定义，保存 | 联动设置行消失 | ok |
| D-10 | 复制负责人字段 | 副本同样是人员单选，可选范围和取值来源跟着走 | 复制功能已取消 |
| D-11 | 测完删掉副本，把负责人和协作人恢复成全部 + 自定义，保存 | 后面填报用 | 复制功能已取消 |

## 3. 选人弹框（范围=全部）

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| F-01 | 添加数据，点负责人 | 弹框可拖拽；顶部是已选区（此时「未选择人员」）；左侧有部门、角色、人员；中间未点部门，右侧提示「请选择部门」、不请求名单；底部有取消和确定 | |
| F-02 | 切到部门，点一个有人的节点 | 这时才分页查出该节点及下级里的启用用户，每页 10 条；甲不会在两个部门节点下重复出现 | |
| F-03 | 切到角色（未点角色时右侧提示「请选择角色」）。点一个角色 | 右侧是拥有该角色的启用用户，每页 10 条 | |
| F-04 | 切到人员，先不要输入 | 中间有搜索框；右侧提示「请输入姓名或用户名搜索」，没有扁平全量名单 | |
| F-05 | 在人员 Tab 输入甲的显示名或部分用户名后失焦或回车 | 列表这时才按关键词分页查询；输入过程中名单不变。停用的丙始终不出现 | |
| F-06 | 点甲，再点确定 | 点甲后弹框不关、行高亮，已选区出现甲和删除图标；点确定后关闭，控件上是甲。再点空白可重新打开，用部门或搜索找到乙并确定，变成乙（单选只有一人） | |
| F-07 | 点协作人 | 底部有确定；点行是勾选，不会立刻关弹框 | |
| F-08 | 先勾甲，确定；再打开，再勾乙，确定 | 标签顺序按选中先后；两人都在 | |
| F-09 | 协作人弹框里把已勾的人取消再确定 | 对应标签消失 | |
| F-10 | 点弹框取消（单选已点人未确定，或多选已勾未确定） | 控件上的人选不变 | |
| F-11 | 设计器预览（顶栏预览若仍是 JSON）或画布字段 | 都不是填报弹框；画布点人名区打不开「选择人员」 | |
| F-12 | 负责人从未选人打开，点甲后点已选区删除，再确定 | 已选区回到「未选择人员」，列表取消选中；确定后控件仍无人 | |

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| L-01 | 数据管理看已保存行 | 负责人、协作人是显示名，不是数字 id；多人顿号分隔；鼠标悬停能看全称（若有 title） | |
| L-02 | 点这两列单元格 | 没有内联编辑框 | |

## 7. 数据联动

把「人员填报」的负责人、协作人改成取值来源=数据联动，条件都是：人员源.工号 等于 当前表.工号。负责人触发人员源.负责人；协作人触发人员源.协作人。保存表单。

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| K-01 | 添加数据，工号不填 | 负责人、协作人都空；**不弹**多条提示 | |
| K-02 | 工号填 `M001`，等约 1 秒 | 负责人=甲；协作人=甲、乙。无报错 | |
| K-03 | 改成 `M002` | 负责人=乙；协作人=乙。显示姓名，不是「已删除」 | |
| K-04 | 改成 `M999`（源表没有） | 两个人员字段清空；不弹多条 | |
| K-05 | 打开人员源，临时关掉工号重复值，再录一条工号 `M001`、负责人乙。回到人员填报添加数据，工号 `M001` | 负责人被清空，提示 `[ 负责人 ] 字段联动查询出多条数据`。协作人按多条记录收集 id（去重保序），**不弹**多条、不截断 | |
| K-06 | 测完删掉人员源里那条重复 `M001` | 避免污染 | |
| K-07 | 设计器把负责人打开禁用，保存。添加数据填 `M002` | 控件灰、不能手选，但仍显示乙。保存后列表是乙。测完关掉禁用 | |
| K-08 | 设计器：另加一个单行文本，选项/取值不要搞混。打开某下拉或选择数据的「其他表数据」树，看人员源 | **没有**负责人、协作人这些人员字段 | |
| K-09 | 负责人联动设置里，触发字段下拉 | 能选到人员源的「负责人」（同为人员单选）；不应拿人员多选去填人员单选 | |
| K-10 | 设计器画布、数据管理单元格改工号 | 画布不查出人；单元格改工号后同一行负责人**不会**自动变，要进添加数据或详情编辑才跑联动 | |

联动写入的人可以不在自定义范围内（手选仍受限）。若要抽查：把负责人改成自定义且只含甲，取值来源仍是联动；填 `M002` 应仍带出乙。测完改回全部。

## 8. 见到就算失败

| 编号 | 现象 |
|---|---|
| X-01 | 调色板仍叫「成员选择」，或和登录人姓名混成一个控件 |
| X-02 | 填报选人走 `/admin/users`（或同类）并对普通账号 403 |
| X-03 | 弹框里能新选停用用户；或已选人省略成「等 N 人」 |
| X-04 | 点清除却打开弹框 / 打开记录详情 |
| X-05 | 列表格子显示纯数字 id（用户还在库里时） |
| X-06 | 人员单选匹配多条记录时自动填了其中一人，或人员多选弹出「查询出多条」 |
| X-07 | 人员单选或人员多选成功放进子表 |
| X-08 | 导入模版出现人员列，或单元格能内联改人选 |
| X-09 | 人员单选点一行就关弹框，或底部没有确定 |

## 不要测（本期）
