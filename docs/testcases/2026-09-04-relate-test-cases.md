# 关联数据、关联子表单 手工测试用例

日期：2026-09-04
范围：关联数据 `relate`、关联子表单 `relate-subform`。对照界面点，不要只看库里的 id。

---

## 测什么

- **关联数据**：在人员表里挑一条工厂数据，两边挂上关系。库里存工厂那条数据的 id，工厂改名后这边刷新跟着变。
- **关联子表单**：装在工厂表上。打开某条工厂详情时，列出「所属工厂」指向它的人员，可翻页。

不要和选择数据 `data` 混：选择数据是挑一行来拷值；关联数据是指向那一行。

---

## 测试用表结构

先建并保存这三张表。

**工厂表**

| 字段标题 | 调色板控件 |
|---|---|
| 工厂编码 | 单行文本 `input` |
| 工厂名称 | 单行文本 `input` |

示例数据：`F001 / 一号厂`，`F002 / 二号厂`。后面再补到 12 条人员时，一号厂要能挂得上。

**人员表**

| 字段标题 | 调色板控件 | 配置 |
|---|---|---|
| 工人名 | 单行文本 `input` | |
| 工人编号 | 单行文本 `input` | |
| 所属工厂 | 关联数据 `relate` | 数据源=工厂表；显示字段=工厂名称 |

**组织表**（测关联本表时再建）

| 字段标题 | 调色板控件 | 配置 |
|---|---|---|
| 名称 | 单行文本 `input` | |
| 上级 | 关联数据 `relate` | 数据源=组织表自己；显示字段=名称 |

工厂表里的关联子表单 **不要提前拖**，测到 R-08 再拖。

---

## 怎么配「所属工厂」

人员表设计 → 从调色板拖「关联数据」→ 右侧「数据源」选「工厂表」→ 「显示字段」选「工厂名称」→ 保存。

可选：

- 「显示在表单中的字段」勾「工厂编码」：选中后控件下方出现「工厂编码：F001」，这个值不另存一列。
- 「填充到表单中的字段」：工厂编码 → 人员表里已有的某个单行文本。拷过去的值以后不会跟着工厂改。
- 「选择过程设置」：勾弹窗表格要显示的列。

## 1. 关联数据

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| R-01 | 人员表添加数据 → 点「所属工厂」→ 弹窗勾「一号厂」→ 确定 → 保存 | 弹窗标题是「选择关联数据」；收起态显示「一号厂」。再开详情仍是「一号厂」 | |
| R-02 | 工厂表把「一号厂」改成「一号厂（新）」→ 回到人员表刷新详情 | 「所属工厂」显示「一号厂（新）」。若 R-01 配过填充，被填充的那个字段**还是旧值** | |
| R-03 | 给「所属工厂」配「显示在表单中的字段 = 工厂编码」。选中一号厂后看控件下方 | 出现「工厂编码：F001」。人员表自己没有多出一列工厂编码（没配填充的话） | |
| R-04 | 「选择过程设置」只勾工厂编码、工厂名称。再打开选记录弹窗 | 表格只有这两列（加序号、勾选）。快捷搜索、分页能用 | |
| R-05 | 再拖一个关联数据到画布，**不选数据源** | 画布提示「请选择主表」。填报里点它没反应 | |
| R-06 | 删掉「一号厂」这条工厂数据 → 刷新那条人员 | 「所属工厂」显示「已删除」。可以清空或改选二号厂 | |
| R-07 | 组织表先录「总部」（上级留空）→ 再录「华东分部」，点「上级」 | 弹窗能选到「总部」。编辑「华东分部」时弹窗里没有它自己 | |
| R-08 | 人员表数据管理看「所属工厂」列 | 显示工厂名称，不是一串 id。这一列没有编辑铅笔 | |
| R-09 | 人员详情（只读）点「所属工厂」显示的文字 | 打开工厂那条数据的只读详情，底部只有「关闭」。关掉后仍在人员详情 | |
| R-10 | 人员详情点「编辑」后再点「所属工厂」 | 打开的是选择弹窗，不是跳转 | |
| R-11 | 「所属工厂」勾必填 → 添加数据不选工厂就保存 | 提示「请填写「所属工厂」」，停在表单上 | |
| R-12 | 同一张人员表再放一个选择数据 `data`，数据源也是工厂表。选一条后保存 | 两个控件并存。改工厂名后：关联数据跟进，选择数据拷出去的值不变 | |
| R-13 | 往子表单里拖关联数据 `relate` | 不插入，提示不能加到子表单 | |

## 2. 关联子表单

预备：人员表「所属工厂」已按上面配好并保存。工厂表还没有关联子表单。

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| S-01 | 工厂表设计 → 拖「关联子表单」 | 弹出「选择关联表单」，能看到「人员表 · 所属工厂」 | |
| S-02 | 选中确定 | 画布出现和子表单类似的表格占位，**占整行**（旁边不会再排别的半宽字段）。表头是「显示的列」的字段标题（如「工人名」「工人编号」），一列一格有竖线，**不是**一长串挤在一起的字段 key。表体有一行空格子。控件标题默认是「人员表」，标题左侧有链式图标，悬停提示关联子表单只读含义。属性里关联表单只读；**「是否可查看详情」默认关闭**；没有必填、禁用、可修改，也**没有「字段宽度」「每页条数」** | |
| S-03 | 再拖一次并选同一条 | 提示「已添加该关联表单」，画布不多出一块 | |
| S-04 | 工厂表「添加数据」 | 抽屉里**没有**关联子表单（无标题、无占位灰字）。网络面板没有对人员表的查询 | |
| S-05 | 保存这条工厂 → 数据管理点开详情 | 关联子表单标题左侧有链式图标（与画布相同）。表格列出「所属工厂」是它的人员，列是配过的那几列，条数对得上 | |
| S-06 | 给一号厂挂 12 条人员。打开一号厂详情 | 默认每页 10 条：第 1 页 10 条，第 2 页 2 条。把每页改成 20，表格重新查出 12 条、只剩 1 页 | |
| S-06a | **「是否可查看详情」仍关闭**时点表格某一行 | 不弹抽屉，鼠标也不是手型 | |
| S-06b | 设计器打开「是否可查看详情」并保存 → 再开一号厂详情，点某一行 | 打开该人员的只读详情抽屉，字段与在人员表数据管理里点开一致（工人名、所属工厂等正确回显）；关掉后仍停在刚才那一页 | |
| S-07 | 一号厂详情点「编辑」 | 这块表格仍只读，没有新增 / 删除。保存工厂后人员数据没变 | |
| S-08 | 把某人员的「所属工厂」改成二号厂 | 一号厂详情少这一条，二号厂详情多这一条 | |
| S-09 | 把关联子表单放进标签页第二个页签。打开工厂详情切过去 | 表格能看、能翻页 | |
| S-10 | 往子表单里拖关联子表单 `relate-subform` | 不插入 | |
| S-11 | 工厂表数据管理列表、「列设置」、下载导入模版 | **没有**关联子表单这一列 | |
| S-12 | 把人员表「所属工厂」的数据源改成别的表并保存。工厂表再拖关联子表单 | 候选里不再出现「人员表 · 所属工厂」 | |
