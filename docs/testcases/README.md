# 手工测试用例说明

日期：2026-08-31  
本目录只放**对照界面执行的测试用例**。功能设计、实施计划仍在 `docs/superpowers/specs/` 与 `docs/superpowers/plans/`。

打开本目录后先读这一份，再按顺序打开下面的用例文件。每条用例记「通过 / 失败」，失败立刻记下编号和现场（表名、字段标题、提示原文）。

## 新增组件时怎么维护

实现或明显改动表单组件后，**同一轮**改本目录，不要只更新规格。尤其是容器、联动、选择数据、流水号、成员/部门这类复杂控件。

1. **专项**：新建或改该能力自己的 `YYYY-MM-DD-<能力>-test-cases.md`（设计、填报、校验、列表、导入等）。
2. **联合**：改 `2026-08-31-complex-form-manual-tests.md`。至少写清和标签页、子表单、数据联动 / 选择数据、流水号叠在一起时怎么表现（能放进 tab / 子表吗、未打开的 pane 还校验吗、联动条件能不能引用、列表会不会多列、删父容器后子内容还在不在）。
3. **本文件**：补目录表、执行顺序、开始前要造的表、破坏性步骤、「不要测」清单。简单字段（单行文本等）只需组合冒烟带一条；复杂组件必须有专项 + 联合。

调色板里还是占位、控件没做完的，不要写成可测功能。

时间不够时：**只做第 1 步冒烟**。冒烟不过就不要往专项里钻。

## 开始前

1. 登录本系统，打开一个**自己的应用**（不要拿别人正在改的表）。
2. 每张表拖完字段立刻点设计器 **保存**，再去工作台添加数据。未保存的表不会出现在联动「选表」列表里。
3. 流水号若带自动计数，确认 MySQL 已有表 `form_serial_seq`。没有则执行 `server/sql/2026-08-31-form-serial-seq.sql`，否则新增保存会失败。
4. 组合用例建议先造：配件台账（含子表「配件明细」）、采购单（见组合用例「准备」一节）。联动专项会再要员工档案、城市目录、奖金申报；人员专项会再要「人员源 / 人员填报」，可以另建，避免和采购单字段搅在一起。
5. 测人员选择前，管理后台至少两名启用用户、一名停用用户。用**没有**用户/部门管理权限的普通账号打开选人弹框，确认走 `/api/org/*` 且不是 403。

## 注意事项

### 操作习惯

- **改条件字段后等约 1 秒**再看联动结果（填报有防抖）。首次进入添加数据会立刻判一次，不必干等。子表 / 主表下拉「其他表数据」也一样：只有选项过滤里引用的字段变了才重查。
- 联动专项**按编号顺序做**，后面的表和数据依赖前面；不要中途改字段标题。
- 设计器画布、数据管理**单元格内联编辑不跑联动**。要验证带出值，进「添加数据」或详情编辑。
- 未打开的标签页里，必填和联动仍然生效；校验失败应跳到出错的 pane。
- `flattenFields` 只展开标签页，不展开子表列。列表不应出现子表里的「物料名称」当主表列；联动条件里的「当前表单字段」一般是主表（含 tab 内），不是子表列。

### 容易误判

- 流水号新增时只读、显示占位，**保存成功后**接口返回和列表里才有号。
- 没有自动计数段时，流水号**不保证唯一**，撞号不算失败。
- 编辑已有记录再保存，流水号必须不变。
- 子表空行保存时会被丢掉；只剩空行且子表必填，应拦 `[子表标题]不能为空`。
- 数字 `0` 算有值，也参与重复值检测。
- 条件字段还空着时联动按 0 条处理，**不弹**「查询出多条」。
- 子表（或主表）下拉「其他表数据」：打开添加/编辑时查一次源表 `records/query` 是对的。之后只切换本列已有选项又出现该请求，算失败。选项过滤绑的是主表字段，设计器里选不到子表列。
- 人员单选联动看的是**记录条数**，不是人数；两条记录各带同一人仍算多条，应清空并提示。人员多选收集 id，不弹多条。
- 人员列显示姓名；用户已从库里消失才显示「已删除」。改显示名后要刷新列表才跟进。

### 不要测（调色板有、控件未完成）

部门选择、关联数据、关联子表单：不要当已交付功能测。拖进子表应被拒绝。

人员单选 / 人员多选**要测**（专项 + 组合 §6）。不要测：部门选择本身；「按部门字段」随部门值清人（控件未完成，属性里空下拉仍要看一眼）；子表里的人员。

明确不做、见到就算失败的现象见各用例文末「X-」表（移动端子表、子表 Excel、两个标签页、两个流水号等）。

### 破坏性步骤

测完若还要继续用同一张表，先恢复再往下：

- 组合用例 **T-16**：删除整个标签页组件
- 组合用例 **C-09**：删除含有子表的 pane
- 组合用例 **P-12**：删除含人员字段的标签页（与 T-16 同类）
- 组合用例 **N-06～N-13**：改流水号分隔符和规则
- 联动专项 **T8**：在源表插入重复编号
- 人员专项 **K-05**：在人员源插入重复工号
- 人员专项 **L-05～L-07**、组合 **P-11**：改显示名 / 停用 / 删除用户（后两项可选，测完恢复）

## 怎么记结果

- 组合用例表格自带「结果」列，打「通过」或「失败」即可。
- 专项文档没有结果列时，把失败编号抄到自己的笔记，带上提示原文。
- 建议先填组合用例文末「总表」（通过数 / 总数），再决定要不要开专项。

## 和自动化的关系

单元测试覆盖 flatten、校验文案、流水号拼接、联动 0/1/多条、人员范围与入库等纯函数，**不能代替**拖放、页签跳转、真实占号、选人弹框、刷新停留。命令写在组合用例文末自动化一节。自动化全绿仍然要做第 1 步冒烟。
