# 数据联动手工测试用例

建议先读本目录 [README.md](./README.md)，做完组合冒烟再跑本专项。按编号顺序做。前面的表和数据会被后面的用例复用，**不要中途改字段标题**。

这一份测的是**主表**数据联动：奖金申报里填了员工编号，姓名、手机、部门等自己带出来。人不用去另一张表勾行。

不要和另外两样搞混：

- **选择数据 `data`**：人点开弹窗勾一条，格子显示「已选择」。
- **下拉「其他表数据」**：选项来源选「其他表数据」，人自己在下拉里挑。

本专项的姓名、手机走的是「取值来源 = 数据联动」；城市走的是「选项来源 = 数据联动」。

对照规格：`docs/superpowers/specs/2026-08-27-data-linkage-design.md`。调色板中文名与 `type` 见 [README.md](./README.md)。

## 怎么给「姓名」配联动

后面 T2、T5 都是这一套，只是本列和「触发以下联动」换成手机、部门等。

奖金申报设计器 → 点 **姓名** → 右侧 **取值来源** 选 **数据联动** → 点 **设置数据联动**：

1. 联动表单选 **员工档案**（可搜索表名。没有就先去保存员工档案）。
2. 条件点 **添加过滤条件**：左边选员工档案的 **员工编号**，中间选 **等于**，右边默认是「当前表单字段」，选奖金申报的 **员工编号**。不必再开一层过滤弹框。
3. 「触发以下联动」右侧选员工档案的 **姓名**。
4. 确定。按钮变成 **已设置数据联动**，右侧出现清除圆圈。再点设计器 **保存**。

画布上配了联动的格子只显示占位（如「请输入」），**不会**出现「张三」。填报、数据管理新增/编辑才会去查。

## 界面上先认清这些

- 单行文本、多行文本、数字、日期选择、时间选择、日期时间、图片上传、文件上传、地址选择：右侧是 **取值来源**，选项是 **自定义**、**数据联动**。
- 下拉单选框 `select`、下拉多选框 `select-multiple`：右侧是 **选项来源**，选项是 **系统字典表**、**其他表数据**、**数据联动**。
- 单选框 `radio`、复选框 `checkbox`：**没有**取值/选项来源，只有「选项字典」，本专项不要去找「设置数据联动」。
- 选择数据 `data` 仍是「数据源」，不走这一套。
- 弹框标题是 **数据联动设置**，可以拖标题栏。没选联动表单时，条件和「触发以下联动」整块不出现。
- 条件那一行的文案是：**联动表单字段满足以下** 〔所有 / 任一〕 **条件时**。左侧占位「联动表字段」；右侧默认「当前表单字段」，图标悬停可切到自定义值。左侧还会列出创建人、更新人、创建时间、更新时间，本轮不要选它们。
- 「触发以下联动」：左边只读，写的是当前正在配的这一列（带图标）；中间是 **联动显示**；右边选联动表里的字段，后面还有 **的值**。右边只能选类型对得上的字段（单行可以对应单行/多行等；数字只能对应数字），不是当前表字段列表。
- 员工编号还空着时，姓名等保持空，**不会**弹出「查询出多条」。填完编号后大约 **1 秒** 才带出（防抖）。
- 设计器画布、数据管理表格里点单元格改，**都不会**跑联动。要带出只能走添加数据或详情里的编辑。
- 新建一张表保存成功后会进设计页，测完记得再保存。

## 1. 设计器

### T1 取值来源 / 选项来源长什么样

1. 打开「奖金申报」设计，点 **姓名**。
2. 右侧应有「取值来源」，选项是 **自定义**、**数据联动**（是下拉，不是单选）。
3. 选 **数据联动**，下方出现「数据联动」，按钮是 **设置数据联动**（还没有清除圆圈）。
4. 再点数字「奖金基数」、日期选择「入职日期」，取值来源同样是自定义 / 数据联动。
5. 点下拉单选框「城市」：右侧是 **选项来源**，选项是 **系统字典表**、**其他表数据**、**数据联动**。
6. 临时拖一个单选框 `radio`、一个复选框 `checkbox` 看一眼：没有取值/选项来源，仍是「选项字典」。看完可删掉。

**期望：** 上面都能对上。

### T2 没配完不能当成已设置

1. 点姓名的「设置数据联动」，弹出 **数据联动设置**。这时只有「联动表单」，还没有条件和触发。
2. 直接点确定 → 提示 **请选择联动表单**，弹框不关。
3. 联动表单选「员工档案」。条件和「触发以下联动」出现。条件空着点确定 → 提示 **请至少添加一条联动条件**。
4. 按上面「怎么配」加条件：员工档案.员工编号 等于 当前表单.员工编号。
5. 「触发以下联动」右侧不选，点确定 → 提示 **请选择触发联动字段**。
6. 右侧选「姓名」，点确定。

**期望：** 按钮变成 **已设置数据联动**，右侧有清除圆圈。触发行：左边只读「姓名」（带单行文本图标），中间「联动显示」，右边是联动表字段，再后面是「的值」。

### T3 「触发以下联动」只列出类型对得上的字段

1. 再打开姓名的数据联动。
2. 右边「触发以下联动」应有：姓名、手机、部门、员工编号（都是单行文本）；**不应有** 奖金基数（数字）、入职日期（日期）。
3. 取消关掉。点本表 **奖金基数**，取值来源选数据联动，联动表选员工档案。
4. 触发下拉里应只有 **奖金基数**，没有姓名。

**期望：** 通过。奖金基数这步可以配完留给 T6：条件和姓名一样，触发选「奖金基数」。

### T4 取消不保存，清除要确认

1. 点 **手机**，取值来源选数据联动，打开设置，选员工档案并配好条件，触发选「手机」，点 **取消**。
2. 按钮仍是 **设置数据联动**（没存进去）。
3. 再配一次并确定，变成已设置。
4. 点清除圆圈 → 弹出标题 **删除**、文案 **确定删除数据联动？** → 点取消，配置还在。
5. 再点清除 → 确定。按钮回到 **设置数据联动**，取值来源仍停在 **数据联动**。
6. 把取值来源改回 **自定义**，下面「数据联动」那一行消失。

**期望：** 通过。T4 做完把手机重新配成已设置（同姓名那套，触发选「手机」），后面填报要用。

### T5 把其余列配齐并保存

按同一套条件配完（每配几列就保存一次奖金申报也行）：

| 本表这一列 | 取值来源 | 联动表 | 条件 | 触发以下联动选 |
|---|---|---|---|---|
| 姓名 | 数据联动 | 员工档案 | 员工档案.员工编号 等于 当前表单.员工编号 | 姓名 |
| 手机 | 数据联动 | 员工档案 | 同上 | 手机 |
| 部门 | 数据联动 | 员工档案 | 同上 | 部门 |
| 奖金基数 | 数据联动 | 员工档案 | 同上 | 奖金基数 |
| 入职日期 | 数据联动 | 员工档案 | 同上 | 入职日期 |

**备注** 保持自定义，用来对照「不会被联动改掉」。

画布上：配了联动的输入框只显示占位，**不会**查出张三。城市如果选项来源还没配完，会显示「请配置选项来源」；配成数据联动之后画布下拉仍是空的（画布不查）。

点设计器 **保存**。

## 2. 填报：对不上 / 正好一条 / 对上两条

### T6 员工编号还空着

1. 工作台打开「奖金申报」→ **添加数据**。
2. 不填员工编号。打开就会判一次，不必干等 1 秒。

**期望：** 姓名、手机、部门、奖金基数、入职日期都是空；没有「查询出多条」提示。备注可以手填，不受影响。

### T7 编号对上正好一条

1. 员工编号填 `E001`，点到别处，等约 1 秒。

**期望：** 姓名张三、手机 13800000001、部门研发、奖金基数 8000、入职日期 2024-01-01（按你档案里实际录的）。没有报错提示。

2. 改成 `E002`，等约 1 秒。

**期望：** 变成李四，以及李四的手机、市场、9000、2024-03-15（按档案）。

3. 保存。到 **数据管理** 看这一行。

**期望：** 各列是李四的姓名、手机这些**字**，不是员工档案那条记录的 id。

### T8 同一个编号对上两条

1. 打开「员工档案」，若「员工编号」开了不允许重复，先关掉并 **保存表单**。再添加一条：员工编号也是 `E001`，姓名 `张三-重复`，手机 `13900000000`，部门 `总经办`，奖金基数 `1`，入职日期任意。
2. 回到「奖金申报」添加数据，员工编号填 `E001`，等约 1 秒。

**期望：**

- 姓名、手机、部门、奖金基数、入职日期被清空。
- 每个被联动的字段各提示一次：`[ 姓名 ] 字段联动查询出多条数据`（标题换成该列）。若标题旁写了说明，提示里会带上，例如 `[ 奖金基数，数字越大给的越多 ] 字段联动查询出多条数据`。
- **城市**这种联动下拉不弹这条提示。
- 不会自动填成张三或张三-重复。

3. 测完删掉员工档案里「张三-重复」那条，避免挡后面。

### T9 编号档案里没有

1. 添加数据，先填 `E001` 带出张三。
2. 把员工编号改成 `E999`（档案里没有），等约 1 秒。

**期望：** 姓名等联动列被清空；**没有**「查询出多条」提示。

## 3. 下拉联动（城市）

条件仍是「来源表某列 = 当前表某一列」，但目标是下拉单选框：对上 1 条会自动选中；对上多条只给选项、不自动选、不弹「多条」提示。

### T10 给「城市」配联动

1. 奖金申报设计里再加一列单行文本 **省份**（取值来源自定义）。
2. 点 **城市**（下拉单选框 `select`）：
   - **选项来源** 选 **数据联动**（不要选「其他表数据」）。
   - 联动表选 **城市目录**。
   - 条件：城市目录.省份 等于 当前表单.省份。
   - 触发以下联动选城市目录的 **城市**。
3. 确定并保存表单。

**期望：** 画布上城市不再显示「请配置选项来源」。画布下拉仍是空的。

### T11 省份空 / 只对上南京 / 对上杭州和宁波

1. 添加数据。省份不填：点开城市，下拉里没有选项，格子是空的；不弹「多条」提示。
2. 省份填 `江苏`，等约 1 秒：城市应 **自动选中** `南京`（目录里江苏只有这一条）。
3. 省份改成 `浙江`，等约 1 秒：下拉里是杭州、宁波，**不会**自动选中某一个，也 **不弹**「多条」提示；刚才的南京应被清掉（已经不在选项里）。
4. 人自己选杭州，保存。数据管理里城市显示杭州。
5. 把省份清空：下拉里没有选项了。格子里**可能还留着**刚才的杭州，这不算失败。再填 `江苏`，会按「只对上一条」写成南京。

## 4. 禁用、不可修改、详情、列表单元格

### T12 禁用了仍能被带出

1. 设计器点 **姓名**，打开 **是否禁用** → 保存。
2. 添加数据，员工编号填 `E001`，等约 1 秒。

**期望：** 姓名是灰的、点不了，但仍显示张三。保存后数据管理里姓名是张三。

3. 测完关掉禁用并保存。

### T13 不可修改：新增能带出，编辑已有记录不改这一列

1. 设计器点 **姓名**，关掉 **是否可修改** → 保存。
2. 添加数据，填 `E002`，姓名应为李四。保存。
3. 数据管理 **点行** 打开详情，**不要**点编辑。

**期望：** 姓名仍是李四。这时即使去员工档案把李四改成别的名字，详情里也不变（只读不查、不写）。

4. 点 **编辑**，不要改员工编号，等几秒。

**期望：** 姓名仍是李四（打开编辑且编号没变，不会用档案里的新名字覆盖）。

5. 把员工编号改成 `E001`，等约 1 秒。

**期望：** 姓名 **仍是李四**（不可修改 + 正在编辑已有记录，联动不能改姓名）。手机、部门等还能改的列应变成张三的。

6. 取消编辑。把姓名的「是否可修改」重新打开并保存，方便后面测覆盖。

### T14 打开编辑不改编号，手机不应跟着档案改

1. 用 T7 保存过的李四那条（或再新建一条 `E002` 并保存）。
2. 到员工档案把李四的手机改成 `13700000000` 并保存那条记录。
3. 数据管理打开这条奖金申报 → 编辑，**不要改**员工编号。

**期望：** 手机仍是当初带出的 `13800000002`，不会变成 137。

4. 把员工编号改成 `E001`，等约 1 秒；再改回 `E002`，再等约 1 秒。

**期望：** 改回 `E002` 之后按档案**现在**的内容重查，手机变成 `13700000000`。

### T15 列表单元格改不了联动列，改编号也不会当场带出

1. 打开奖金申报 **数据管理** 表格。
2. 姓名、手机、部门、奖金基数、入职日期、城市这些配了数据联动的列，单元格里 **没有** 编辑按钮。
3. 员工编号、备注、省份仍可以点单元格改。
4. 在单元格里把员工编号改成 `E001`。

**期望：** 同一行姓名 **不会** 马上变成张三。要带出只能进详情点编辑（且姓名没有锁「不可修改」）。

## 5. 对照与收尾

### T16 不要和选择数据、其他表数据搞混

这一轮 **不必** 再去配选择数据或其他表数据，只确认：

- 奖金申报「姓名」是取值来源 **数据联动**，标题前是链式联动图标，**不是**「受选择数据填充」那种连接图标。
- 「城市」是选项来源 **数据联动**，不是「其他表数据」。
- 若旁边另有一列下拉是「其他表数据」：打开添加/编辑会查一次来源表；之后只换该下拉已有选项，Network 里 **不应**再出现来源表的查询。主表对照子表专项 G-07，子表对照 F-33，组合用例 C-14。

### T17 设计器不能靠复制字段来克隆联动

1. 设计器点姓名，看画布上的浮动按钮和右侧属性。
2. **没有**「复制」。不能靠复制字段把联动配置拷到另一列。
