## 怎么测

1. 先做 **§0 冒烟**。过不了就停，先修主路径。
2. 再按 §1～§6 做组合能力。
3. 子表单细节、联动 0/1/多条、人员选框与范围，回到对应专项文档接着勾。
4. 改条件字段后大约等 **1 秒** 再看联动结果（防抖）。子表 / 主表下拉「其他表数据」也一样：只有过滤里用到的字段变了才重查。
5. 测 F-33 / C-14 时打开浏览器 Network，过滤 `records/query`。

## 2. 流水号

默认拖入：分隔符 `-`，规则为「当天 `YYYYMMDD`」+「起始 1 / 5 位 / 不重置」。今天（上海）若是 2026-08-31，第一条带计数的号形如 `20260831-00001`。采购单还加了「单号前缀」字段段，所以实际更像 `PO-20260831-00001`（空片段不参与拼接，不会出现 `PO--00001`）。

| 编号 | 步骤 | 期望 | 结果 |
|---|---|---|---|
| N-01 | 选中流水号 | 属性有分隔符、规则列表、一个「添加」按钮（点开才看到四类，不直接平铺）；**没有**起始值/日期格式等详细项铺在面板上；**没有**必填、禁用、可修改、不允许重复值 | ok |
| N-02 | 画布上流水号 | 只读输入框，不让填 | ok |
| N-03 | 添加数据不填单号前缀，保存 | 前缀段为空被跳过；号类似 `20260831-00001`（没有 `PO-`） | ok |
| N-04 | 再新建一条，前缀填 `PO` | 序号 +1，如 `PO-20260831-00002` | ok |
| N-05 | 打开 N-04 那条编辑备注再保存 | 流水号字符串完全不变 | ok |
| N-06 | 分隔符改成空，保存表单；再新建一条（前缀 `PO`） | 各段直接相连，如 `PO2026083100003`（没有 `-`；序号接着走） | ok |
| N-07 | 分隔符改回 `-` 并保存表单 | 后续新记录又带 `-` | ok |
| N-08 | 点「添加」，看下拉里的「自动计数」 | 该项禁用，选不了，加不进第二段计数 | ok |
| N-09 | 删掉计数段，保存表单，再新建 | 能保存表单、能新增；号码里没有 `0000x`。没有计数时**不保证唯一** | ok |
| N-10 | 点「添加」→「自动计数」，弹框里起始 1、5 位后确定。再点「添加」→「固定字符」，弹框填 `TEST` 后确定，拖左侧排序图标到最前（点摘要会打开弹框，不要整行拖） | 新记录以 `TEST-` 开头 | ok |

| N-13 | 点字段段，弹框里引用字段选「单号前缀」；把前缀字段删掉后再看流水号规则 | 该段摘要标「字段已删除」或同类提示 | ok |
| N-14 | 列表流水号列 | 显示完整字符串；**不能**单元格内联编辑 | ok |
| N-15 | 下载导入模版 | **没有**流水号列 | ok |
| N-16 | 导入几行（含单号前缀列） | 导入后每行由后端生成流水号，不是 Excel 里指定的 | ok |
| N-17 | 试图把流水号生成 `serialNumber` 拖进子表单 `subform` | 提示「该字段暂不支持添加到子表单」 | ok |
| N-18 | 流水号放在未打开的 pane 里；根上字段填好保存 | 仍然生成号码（未打开 pane 也提交） | ok |

## 8. 见到就算失败

| 编号 | 现象 |
|---|---|
| X-01 | 一张表出现两个标签页 `tabs` 或两个流水号生成 `serialNumber` |
| X-02 | 提交数据里出现标签页自己的 key，或 `data` 按 pane 名嵌套 |

| X-06 | 编辑保存后流水号被改掉或被客户端提交覆盖 |

| X-08 | 子表 Excel 导入、按子表列筛选排序、移动端子表样式 |
| X-09 | 选人弹框对普通账号 403；列表在用户/部门仍在库里时显示纯 id |
