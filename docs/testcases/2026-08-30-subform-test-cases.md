## 测试用表结构

在同一应用里建下列表单。每张表拖完字段后点设计器 **保存**；有示例数据要求的，保存后再去工作台 **添加数据** 录入。各节只写本节要动的字段；未列出的按本表已有结构测。调色板中文名与 `type` 对照见 [README.md](./README.md)。

### 采购单

主表：

| 字段标题 | 组件 `type` | 配置 / 条件 |
|---|---|---|
| 工厂 | 单行文本 `input` | 自定义 |
| 设备编号 | 单行文本 `input` | 自定义；§11 整表联动条件 |

子表「**订单明细**」：

| 字段标题 | 组件 `type` | 配置 / 条件 | 用于 |
|---|---|---|---|
| 物料名称 | 单行文本 `input` | 自定义；§10 改为取值来源=数据联动 | 冒烟 S-02；§10 行内联动（带出名称）；§11 对照目标 |
| 数量 | 数字 `number` | 自定义 | 冒烟 S-02 |
| 编码 | 单行文本 `input` | 自定义 | §7 重复值 |
| 物料 | 选择数据 `data` | 数据源=设备台账。本列**不要配**「显示在表单中的字段」，不要配回显。选中后本格显示「已选择」 | §9 |
| 名称 | 单行文本 `input` | 自定义 | §9；在「物料」上配填充：设备台账.设备名称 → 订单明细.名称 |
| 设备照片 | 图片上传 `image` | 自定义 | §9 P-16/P-17 |

| 所属部门 | 部门单选 `dept` | 可选范围=全部 | §9 P-16 |
| 设备编号选项 | 下拉单选框 `select` | 其他表数据=设备台账.设备编号 | §5 F-30～F-36 |
| 物料编码 | 单行文本 `input` | 自定义 | §10 行内联动条件 |

「物料」配法（对照界面，不要按「回显=设备编号」去找设置）：

1. 先保存「设备台账」。数据源只列出本应用**已保存**的其他表，不含当前采购单。
2. 把选择数据 `data` 拖进「订单明细」（松在子表上），点子列表头，字段标题改成「物料」。
3. 右侧 **数据源** 点开，选「设备台账」。
4. 右侧会出现「填充到表单中的字段」「选择过程设置」，**不会**出现「显示在表单中的字段」（D-25）。不要在「选择过程设置」里勾「设备编号」当回显：那只改弹框表格列。
5. 再拖一列单行文本「名称」。回到「物料」，点「填充到表单中的字段」→ 新建：数据源表「设备名称」→ 本表单「订单明细.名称」→ 确定。
6. 保存。填报选一条后：「物料」格子是「已选择」，右侧有圆形清除图标；「名称」才是该条的设备名称（如对应 `E001` 的名称）。点清除只清「物料」，「名称」还在。

## 10. 行内联动

这一节测的是：**订单明细某一行里填了物料编码，同一行的物料名称自动带出物料档案里的名称**。一行只带这一行，不会改旁边那一行。

### 先准备两张表

1. **物料档案**（本应用里另建一张表，先保存）：主表两个单行文本 `input`——「编码」「名称」。工作台添加数据，至少两条：编码 `A01`、名称随便（如 `档案01`）；编码 `B02`、名称另一条（如 `档案02`）。
2. **采购单** → 「订单明细」里本节只用这两列（和 §9 的选择数据「物料」不是同一列，没有「物料」也能测本节）：
   - **物料编码**（单行文本 `input`）：人手工填编码的那一列。不要和「编码」（§7 测重复值用的那列）混成两个都叫「物料编码」。
   - **物料名称**（单行文本 `input`）：下面配成数据联动，用来自动带名称。

若「订单明细」里已经有两列都叫「物料编码」，填报时填左边一列、联动却绑着右边一列，名称不会带出。测本节前先改标题或删掉多余列，保证条件里选的就是你要填的那一列。

### 怎么给「物料名称」配联动

采购单设计器 → 点「订单明细」表头「物料名称」→ 右侧 **取值来源** 选 **数据联动** → 点 **设置数据联动**：

1. 联动表选 **物料档案**（没有就先去保存物料档案）。
2. 条件点添加：左边选物料档案的 **编码**，中间选 **等于**，右边点「当前表单字段」，选 **订单明细.物料编码**（文案必须带「订单明细.」，不要选成「当前表单.物料编码」——那是采购单主表上若也有同名列才会出现）。
3. 「触发以下联动」选物料档案的 **名称**。
4. 确定，再点设计器 **保存**。
