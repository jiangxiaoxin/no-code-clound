# 子表单功能测试用例

建议先读本目录 [README.md](./README.md)，做完组合冒烟再跑本专项。

日期：2026-08-31  
对照：`docs/superpowers/specs/2026-08-30-subform-design.md`  
范围：表单设计、填报、入库校验、数据管理、子表选择数据 `data`、行内联动、整表联动、子表下拉单选框 `select`「其他表数据」何时请求源表。不含移动端、快速填报、子表权限、嵌套子表、子表 Excel。

预备：准备一个应用，至少两张已保存表单。下文用「采购单」（当前表）和「设备台账」（他表）。设备台账主表有单行文本 `input`「设备编号」，并带一张子表单 `subform`「配件明细」（单行文本 `input` 名称、数字 `number` 数量）。采购单主表有单行文本 `input`「工厂」「设备编号」，再拖入子表单 `subform`「订单明细」。调色板中文名与 `type` 对照见 [README.md](./README.md)。

## 1. 设计器：允许的子类型

| 编号 | 步骤 | 期望 |

| D-01 | 往子表拖入：单行文本 `input`、多行文本 `textarea`、数字 `number`、日期选择 `date`、时间选择 `time`、日期时间 `datetime`、单选框 `radio`、复选框 `checkbox`、下拉单选框 `select`、下拉多选框 `select-multiple`、地址选择 `address`、图片上传 `image`、文件上传 `file`、选择数据 `data` | 都能成为一列；画布表头出现对应标题 |

| D-04 | 把字段拖到子表外面的空白画布 | 加到主表，不是子表列 |
| D-05 | 尝试把已有主表字段拖进子表，或把子列拖出变主表 | 不能换层级；子列只能在本子表内上移/下移 |

## 5. 填报：单元格与只读

| 编号 | 步骤 | 期望 |
|---|---|---|
| F-20 | 单行文本 `input`、数字 `number`、日期选择 `date` / 时间选择 `time` / 日期时间 `datetime`、单选框 `radio` / 复选框 `checkbox`、下拉单选框 `select` / 下拉多选框 `select-multiple`、地址选择 `address` | 与主表同类控件相同，能改、能清 |

| F-24 | 子表「是否禁用」打开 | 整表只读：不能改单元格，没有添加/插入/复制/删除 |
| F-25 | 子表「是否可修改」关掉；新建 | 仍可填、可增删行 |
| F-26 | 同上；打开已有记录点编辑 | 整表锁住，含增删行 |
| F-27 | 数据详情只读 | 同一表格只读，无增删 |
| F-28 | 固定前 1 列，列足够多，横向滚动 | 操作列始终固定；再固定第 1 个字段列 |

| F-30 | 子表下拉单选框 `select`（也可测下拉多选框 `select-multiple`）选项来源=其他表数据 `table_data`，源表该字段有记录 | 打开下拉能看到去重后的选项，与主表「其他表数据」相同 |
| F-31 | 同上，源表没有记录或过滤后 0 条 | 下拉为「无数据」，不是报错 |
| F-32 | 数据管理勾选一行点「编辑」 | 子表下拉（其他表数据 `table_data` 或行内联动 `linkage`）打开即有选项，不必先开详情再点编辑 |
| F-33 | 子表下拉单选框 `select` 选项来源=其他表数据 `table_data`、**没有**选项过滤。打开 Network，在子表里切换该下拉的已有选项 | 打开编辑时会请求一次源表 `POST .../forms/{源表id}/records/query`；之后只改本列选项时**不再**请求。下拉仍有原来那些选项 |
| F-34 | 同上，选项过滤绑**主表**字段（例如工厂；设计器过滤里选不到子表列）。改工厂 | 约 1 秒后会再请求源表；下拉选项随过滤结果变。只改本列自己的值仍不请求 |
| F-35 | 无选项过滤（或过滤条件当前值相同）。再点「添加」一行，打开新行同一下拉 | 不额外请求源表；新行也能看到已有选项 |
| F-36 | 改一个**没被**选项过滤引用的主表字段 | 不请求源表 |

## 9. 子表选择数据

预备：他表有至少 3 条记录。子表有「物料」（选择数据）、「名称」（文本）。填充规则：他表标题 → 本行名称。

| 编号 | 步骤 | 期望 |
|---|---|---|
| P-01 | 过滤条件不引用本子表列；当前行为空；一次勾 3 条确定 | 变成 3 行；第 1 条写当前行，其余插在后面；名称被填充 |
| P-02 | 过滤条件「他表.xxx = 订单明细.某列」 | 该行弹窗只能选 1 条（与主表现在一样） |
| P-03 | 当前行已经有选中 id，再打开 | 只能改选 1 条 |
| P-04 | 过滤只引用主表「工厂」，当前行为空 | 仍可多选 |
| P-05 | 多选时勾选当前页即可 | 没有跨页 Shift 连选 |
| P-06 | 选 3 条但再加就会超过 200 行 | 多出来的不要，提示「子表单最多 200 行」 |
| P-07 | 改选另一条源记录 | 映射列被新值覆盖 |
| P-08 | 清空本列选择数据 | 清掉该行 id；已填充到名称的值**保留** |
| P-09 | 复制带选择数据的行 | 拷贝 id 和本行值，不重新查、不重填 |
| P-10 | 源表后来改了标题 | 已写入的名称不跟着改；控件回显标题仍按 id 再查 |
| P-11 | 详情只读点选择数据 | 只回显标题，不打开选记录 |
| P-12 | 填充目标配置 | 不能选主表字段 |
| P-13 | 选择数据开不允许重复值；两条主表记录选同一源 id | 第二条不能提交 |
| P-14 | 同一子表两行选同一源 id（开了行内或跨记录唯一） | 不能提交 |
| P-15 | 主表上的选择数据 | 仍是单选；确定后只填主表，不灌子表 |

## 10. 行内联动

预备：子表有「物料编码」「物料名称」。名称列取值来源=数据联动。条件：`他表.编码 = 订单明细.物料编码`。下拉展示应是「订单明细.物料编码」，不要写成「当前表单.物料编码」。

| 编号 | 步骤 | 期望 |
|---|---|---|
| L-01 | 设计器条件右侧 | 主表字段显示 `当前表单.{标题}`；本子表列显示 `{子表标题}.{标题}`；存盘仍是字段 key |
| L-02 | 第一行填编码 `A01` | 约 1 秒后只第一行名称带出；第二行不变 |
| L-03 | 第二行填 `B02` | 只改第二行名称 |
| L-04 | 条件引用主表「设备编号」；改主表设备编号 | 各行各自重查 |
| L-05 | 查到 0 条 | 该行该列按主表 0 条规则清空（下拉则选项空） |
| L-06 | 查到多条（非下拉） | 清空并提示 `[ 字段标题 ] 字段联动查询出多条数据` |
| L-07 | 画布 | 不发联动查询 |
| L-08 | 详情只读 | 不查、不写 |
| L-09 | 子表禁用 | 联动仍可写入该列（与主表禁用字段相同） |
| L-10 | 子表或该列不可修改，且在编辑已有记录 | 不写 |
| L-11 | 打开编辑时条件相对进入时没变 | 下拉只刷新选项，不改已有值 |
| L-12 | 选择数据 `data` / 单选框 `radio` / 复选框 `checkbox` 列 | 属性里不出现数据联动 |
| L-13 | 名称列是联动下拉。条件字段没变，只改该列已选选项 | 不再请求联动源表 `records/query` |

## 11. 整表联动

预备：设备台账有 1 条设备编号 `E001`，其配件明细 3 行。采购单子表取值来源=数据联动：条件 `他表.设备编号 = 当前表单.设备编号`；赋值数据源=配件明细；对照 名称→物料名称。

| 编号 | 步骤 | 期望 |
|---|---|---|
| W-01 | 设置弹框 | 能选联动表（含当前表）；条件右侧只有主表字段（`当前表单.{标题}`），没有子表列；能选源子表；至少一条对照 |
| W-02 | 缺表 / 缺条件 / 缺源子表 / 对照为空就确定 | 不能保存为已设置；不查询 |
| W-03 | 新建填 `E001`（他表正好 1 条） | 子表被替换成 3 行对照结果 |
| W-04 | 改成对不上的编号（0 条） | 子表变成 `[]`，不提示 |
| W-05 | 条件能命中他表 2 条 | 子表变成 `[]`，提示 `[ 子表标题 ] 字段联动查询出多条数据`（有说明则带上） |
| W-06 | 条件未就绪（设备编号还空着） | 子表 `[]`，不提示 |
| W-07 | 用户刚手加了行，再改设备编号命中 1 条 | 手加行被整表覆盖掉 |
| W-08 | 源行超过 200 | 截到 200，提示「子表单最多 200 行」 |
| W-09 | 已配整表联动 | 新建不再用默认行数铺空行 |
| W-10 | 打开已保存记录，条件没变 | 不覆盖手改过的子表 |
| W-11 | 打开后改设备编号 | 按 0/1/多条重写 |
| W-12 | 详情只读 | 不查整表联动 |
| W-13 | 子表不可修改且编辑已有记录 | 不覆盖 |
| W-14 | 子表禁用 | 仍覆盖（与主表禁用字段仍可被联动写入一致） |
| W-15 | 清除联动 | 二次确认文案「确定删除数据联动？」 |
| W-16 | 主表联动、选择数据的表字段下拉 | 仍然没有 `subform`（`include=subform` 只给整表弹框用） |
